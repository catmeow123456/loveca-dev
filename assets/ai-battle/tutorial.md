# 围绕近期计划管理手牌

这份说明提供各卡组通用的决策方法。具体费用曲线、关键组合与风险偏好读取本局构筑手册，不照搬其他卡组的开局。

“轴”表示每个自己的回合主要阶段结束时，期望形成的舞台成员费用组合及其后续衔接。手册中的 T1、T2 指自己的第一、第二个回合，箭头连接相邻自己的回合，同一节点中的“＋”表示同时在场的不同成员；这些费用不是本回合需要支付的能量总和。沿轴发展时，比较最终舞台的成员总费用、各槽位费用分布、成员数量、颜色、HEART、BLADE、能力和下一回合的换手基础，实际支付逐项采用合法候选的 energyCost，并另计能力费用。

舞台成员总费用的积累本身具有发展价值：本回合支付的能量能转化为留在舞台上的费用基础，后续换手可以利用它继续成长。因此，即使登场效果暂时不能发动、当前 HEART 只小幅变化，也要评价费用基础的增加及其对下一回合预算的贡献。总费用只统计己方舞台顶层成员，并同时保留各槽位分布；实际换手按被替换的单名成员当前有效费用与合法候选核算，不能合并多个成员的费用减免。成员离场或被低费成员替换时，也要计入失去的费用基础。总费用、即时表演资源和后续可执行路线一起比较，不把总费用当作已经支付过的历史能量或额外 HEART。

每次选择先根据当前舞台与手牌判断本局可走的轴、本回合目标和下一步缺件，再选择当前动作。起手换牌、检视、回收、弃手和盖牌共同服务这条近期路线，优先保留或寻找不可替代的衔接牌，同时准备 LIVE。推荐轴可作为健康发展的基准；缺件、实际能量不足、关键颜色或资源受损、对手得分压力改变时，按新局面调整路线。新信息没有改变路线可行性和收益时，继续完成已有衔接，避免只为眼前微小收益消耗下一步关键牌；也不为凑费用数字牺牲更有价值的表演或资源。

对手的公开舞台、成功 LIVE 和已展示卡牌尚未形成近期胜利压力时，可以优先积累舞台费用基础、保留已持有的 LIVE，为下一回合准备更完整的表演；当回合少量 HEART 损失可以与 BLADE、费用基础和后续资源收益共同权衡。面对明确抢分或胜利压力时则提高即时表演的优先级。对手节奏只根据公开信息判断；手中没有 LIVE 时，把寻找 LIVE 作为计划中的缺口，不能声称已经囤有资源。

1. 每次选择先确认本回合的目标，以及自己接下来一至两个回合需要补什么：舞台 HEART／颜色、声援 BLADE、能争取分数的 LIVE，还是找到这些牌的机会。用当前手牌、舞台可作换手的成员、实际能量和可见回收目标检验计划。未知抽牌只是可能补充；不能把计划依赖的牌假定为已经持有。
2. 按用途评价整手牌：近期会用的登场／换手成员、计划要唱的 LIVE、检视／回收入口、必要的能力支付手牌，以及没有近期用途的剩余牌。理想手牌能让连续几个操作衔接，不是高费或同类牌越多越好。留牌要能指出预计何时、在哪个位置、以什么费用使用；不同卡名也可能承担相同用途、争用同一槽位与能量，不能将这些互斥升级全都算作必留资源。已有合适备选后，多余成员可用于换牌、弃手或盖牌过牌。仍要保留必要的能力支付手牌。
3. 起手换牌是第一次重整资源。先保住能执行的早期动作和下一步衔接，再保留有实现路径的 LIVE 或资源入口，换回重复、断档或近期用不上的部分。检查费用曲线时用换手后的应付费用：高费牌若能由早期成员衔接就未必卡手；低费牌若不能补色、提供有效能力或支撑下一步，也未必值得全部保留。手牌已支持计划时可全部保留；缺关键起点时应争取找到起点。
4. 主要阶段把本回合能量换成舞台提升、得分机会或后续资源。比较一连串可衔接动作的总支付和最终舞台；同一手牌的不同换手位置互斥，花得最少未必收益最高。普通能量下回合恢复，留能量必须有恢复前的具体用途。当前够唱一张低分 LIVE 后，仍要检查后续升级和 LIVE 供给；缺 LIVE 时，有检视／回收能力的成员可能比同等场攻的无能力成员更有用，也可能值得付出少量场攻。刚登场成员不能立即再被普通换手，后续抽取或效果目标须等新窗口确认。
5. 在进入 LIVE 设置前准备得分资源。比较手中单张和多张 LIVE 的合计需求、颜色与可实现分数，兼顾自己和对手的成功区进度。舞台足够而手里只有低分 LIVE 时，提前考虑检视、回收或为下一回合过牌；不要等设置阶段才发现没有高分牌。选择检视／回收目标时看它对计划的贡献，已有足够 HEART 时比较实际分数，不能仅因某张需求较低就称它得分最高。
6. LIVE 设置同时决定本次表演和下回合手牌。先选当前可达且值得投入的 LIVE 组合，再保留近期升级、下次 LIVE、资源入口与确需支付的牌，评估把剩余成员盖下换新牌。即使已经盖了一张 LIVE，仍可在合法设置额度内盖多余成员改善后续手牌；没有 LIVE 时也可过牌。先决定最终要盖哪些、共几张，再逐次选择并确认：确认后才按盖牌数抽牌，不能看过新抽牌再追加本次设置。不能因为抽牌不保证找到目标就总是停止过牌，也不能无条件盖满或把唯一关键资源耗尽。
7. 设置前区分三种情况：当前资源加可确定支付的能力已经满足；仍需未知声援补足、存在风险；即使用已知构筑和可用效果允许的乐观上限也无法满足。最后一种不能以“赌声援能唱成”为理由投入 LIVE。上限足够只证明可能，指定色、实际判心分布和资源代价仍决定是否值得尝试；纯为过牌盖 LIVE 时，比较保留它并盖多余成员的价值。公开对手压力可以影响风险偏好，不会令不可能的组合变为可行。
8. 效果窗口遵守本次数量、可跳过与排序约束；可选弃手要比较被弃牌在计划中的用途。声援、判定与分数由引擎执行。有多个成功 LIVE 可选择时，按规则选入成功区，并考虑其余牌随后进入的区域与回收价值。每个动作后用新局面重新评估计划，只输出本次选择及简短、与选择一致的取舍依据；不假定上一决定的计划仍然成立，不为迅速结束测试而认输。
