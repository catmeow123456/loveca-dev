# 围绕近期计划更新手牌

这份说明提供各卡组通用的决策方法。具体费用曲线、关键组合与风险偏好读取本局构筑手册，不照搬其他卡组的开局。

“轴”表示每个自己的回合主要阶段结束时，期望形成的舞台成员费用组合及其后续衔接。手册中的 T1、T2 指自己的第一、第二个回合，箭头连接相邻自己的回合，同一节点中的“＋”表示同时在场的不同成员；这些费用不是本回合需要支付的能量总和。沿轴发展时，比较最终舞台的成员总费用、各槽位费用分布、成员数量、颜色、HEART、BLADE、能力和下一回合的换手基础，实际支付逐项采用合法候选的 energyCost，并另计能力费用。

舞台成员总费用用于判断后续换手衔接，不是独立的得分目标。优先比较本轮可实现的 LIVE 分数、指定色、声援、资源获取和组合条件，再评价下一回合的费用基础。即使总费用或 HEART 上升，失去 BLADE、关键同伴或回收入口也可能使整条路线变差。实际换手按被替换的单名成员当前有效费用与合法候选核算，不能合并多个成员的费用减免；成员离场时同时计入失去的表演资源与衔接机会。

**平换（同费用成员换手）通常消耗一张手牌，零能量不等于免费。** 没有明确净收益时，优先保留原成员和手牌。执行前核对实际离场对象及其触发条件，比较替换后的 HEART、BLADE、临时加成与后续换手限制；新成员本回合不能立即再被普通换手。登场／离场收益、补齐关键颜色、增加必要声援或重新使用能力，都须有可兑现的条件与用途，不能把新成员的离场能力算作旧成员离场的收益。仅因动作可执行、支付为零、颜色更多或“以后可能有用”，不足以支持平换。

将平换与保留现状比较：这张手牌还可用于后续升级、能力支付或 LIVE 盖牌周转；回收重复且近期用不上的牌也不自动构成有效补偿。若平换能改善当前争胜机会、取得必要资源或完成具体发展路线，即使净亏手牌也可以选择，tradeoff 简述“付出什么，换来什么”。这是取舍倾向，不是禁止平换或一律惜牌；必要的弃牌支付和冗余成员盖牌周转仍应正常比较。

每次选择先确认本回合目标、可执行的衔接和下一步缺件。起手换牌与每轮 LIVE 设置都是游戏规则提供的手牌更新机会，与检视、回收、弃手共同服务这条近期路线。每轮重新评价留牌：已有替代、争用同一位置和预算、或原计划已完成的牌，可以换成寻找缺件的新机会；曾经是关键轴件，不代表此后始终必须保留。推荐轴用于检查发展是否连贯，缺件、预算或对手压力变化时调整，不为凑费用数字牺牲更有价值的表演或资源。

对手的公开舞台、成功 LIVE 和已展示卡牌尚未形成近期胜利压力时，可以优先积累舞台费用基础、保留近期有实现路径的 LIVE，为下一回合准备更完整的表演；当回合少量 HEART 损失可以与 BLADE、费用基础和后续资源收益共同权衡。面对明确抢分或胜利压力时则提高即时表演的优先级。对手节奏只根据公开信息判断；手中没有 LIVE 时，把寻找 LIVE 作为计划中的缺口，不能声称已经囤有资源。

1. 每次选择先确认本回合的目标，以及自己接下来一至两个回合需要补什么：舞台 HEART／颜色、声援 BLADE、能争取分数的 LIVE，还是找到这些牌的机会。用当前手牌、舞台可作换手的成员、实际能量和可见回收目标检验计划。未知抽牌只是可能补充；不能把计划依赖的牌假定为已经持有。
2. 按用途评价整手牌：近期会用的登场／换手成员、计划要唱的 LIVE、检视／回收入口、必要的能力支付手牌，以及没有近期用途的剩余牌。理想手牌能让连续几个操作衔接，不是高费或同类牌越多越好。留牌要能指出预计何时、在哪个位置、以什么费用使用；不同卡名也可能承担相同用途、争用同一槽位与能量，不能将这些互斥升级全都算作必留资源。已有合适备选后，多余成员可用于换牌、弃手或盖牌过牌。仍要保留必要的能力支付手牌。
3. 起手换牌先确定保留集合，再提交其余要换回卡组的牌。保住能执行的早期动作、必要衔接和有实现路径的 LIVE／资源入口；重复、互斥或近期用不上的部分用于寻找缺件。已有舞台路线但缺 LIVE，也要比较换新机会，不能只在完全无法展开时换牌。按实际换手费用判断高费牌是否能衔接；低费牌也须有补色、能力或发展用途。整手牌都有近期用途时可以全部保留。
4. 主要阶段比较可衔接动作的总支付、最终舞台与剩余手牌。同一手牌的不同位置是互斥选项，按各自被替换成员计算净收益；付费路线若仍付得起后续能力，并能保住更多 BLADE、关键效果或费用基础，应与零费路线比较，省下没有近期用途的能量不是收益。普通能量下回合恢复，只为恢复前的具体动作预留。当前够唱一张低分 LIVE 后，仍要检查升级和 LIVE 供给；缺 LIVE 时，资源入口可比纯场攻更重要。刚登场成员不能立即再被普通换手，后续抽取或效果目标须等新窗口确认。
5. 在进入 LIVE 设置前准备得分资源。比较手中单张和多张 LIVE 的合计需求、颜色与可实现分数，兼顾自己和对手的成功区进度。舞台足够而手里只有低分 LIVE 时，提前考虑检视、回收或为下一回合过牌；不要等设置阶段才发现没有高分牌。选择检视／回收目标时看它对计划的贡献，已有足够 HEART 时比较实际分数，不能仅因某张需求较低就称它得分最高。
6. LIVE 设置按“表演目标 → 近期保留集合 → 周转剩余牌 → 确认”决策。先核对单张或组合 LIVE 的合计需求，计入本次可支付且满足条件的补心能力，再区分确定满足、需要声援和乐观上限仍不足。声援按实际 BLADE、已知顶牌和构筑判心计算指定色与总量；DRAW 不增加声援次数，成功后奖励不能用于满足本次成功条件。输入的印刷声援基线不含后续卡效与需求修正，正缺口须有实际补足来源；上限足够也不保证颜色命中。缺少关键衔接、将使后续舞台停滞时，提高找件优先级：保住近期可争取的表演与必要成员，把没有近期实现路径的 LIVE 与冗余成员一起比较周转，即使那是唯一 LIVE。盖 LIVE 也能增加补抽机会，须权衡失去它的代价；不能为过牌追加高需求 LIVE，拖垮本可争取的表演。多抽只增加找件机会，不保证命中；周转收益与本次得分机会分别评价。
7. 确定本次要唱的 LIVE 后，为保留牌列出接下来一至两个自己回合的具体用途、位置和支付预算，按各轮恢复与常规补能后的预算核对；不能因当前零能量，或只看最近一轮而丢掉随后一轮已有预算的必要衔接。必要能力支付牌也计入保留集合。同名重复牌或不同名的互斥终端分别核对，不能共用同一槽位、预算或笼统的“以后衔接”理由。剩余重复、互斥或无近期用途的牌优先盖下寻找缺件。盖成员不耗能量、不移走舞台成员，确认后按最终盖牌数等量补抽；无 LIVE、零能量、已盖一张都不是停止理由。每盖一张后仍按当前事实检查剩余额度与留牌用途，先完成集合再确认；确认后的新牌不能追加本次设置或返回主要阶段登场。tradeoff 简述盖/撤对象、保留牌的近期用途；确认时交代最终盖牌/补抽数和不再追加的理由。剩余牌确有用途或已达额度时可以停止，不无条件盖满。
8. 效果窗口遵守数量、可跳过与排序约束。可选费用先核对本次实际命中的条件、奖励及失去的手牌／舞台／休息室用途；没有可兑现收益时优先不发动，不能仅因有合法目标就支付。声援、判定与分数由引擎执行。成功 LIVE 的选择兼顾其余牌的去向与回收价值；失败 LIVE 不能算作后续仍在场的减免来源。每个动作后按 context 中的真实结果和当前资源重新检查衔接，已知顶牌按实际抽牌时点使用。只输出本次选择及简短、与选择一致的取舍依据，不为迅速结束测试而认输。

## 自送回收、腾位与再次登场

“自爆小人”指通过将自身从舞台送入休息室来换取回收等收益的成员。这是各构筑通用的资源转换手段，具体能回收什么、是否支付能量、是否受次数限制，仍由本实例卡文和当前合法候选决定。三个位置都有人，不代表没有补场或资源入口；手牌没有所需成员，也不代表可见休息室中的成员无法在本轮使用。

主要阶段检查这类能力时，比较完整路线，而不是只看自送瞬间减少的 HEART、BLADE 或费用基础：

- 自送腾出哪个位置，失去哪些颜色、声援、常时条件与换手减免；能力支付后还剩多少可用能量。
- 可见目标能否直接补充所需 LIVE，或先回收具有抽牌、检视、回收、回能、加分等能力的成员，再通过其能力继续取得资源。回收一个资源入口，不等于已经得到该入口后续可获得的 LIVE；须核对登场/起动时点、合法目标和费用。
- 回收成员逐位置比较登场预算：可以填原空位，也可以换手到另一个旧成员的位置。高费成员不一定要在空位原价登场，其他位置的减免可能让它低费或零费登场；同时计入该位置被替换成员的损失。原空位可以由已有手牌补上，用来建立后续同伴、名称或区域条件。先补条件再登场收益成员，与反过来操作可能有不同结果。
- 汇总整段实际支付、能确定恢复的能量、最终舞台与手牌用途，再与直接换手和保留现状比较。来源自送后，其原本的换手减免已经失去；不能把同一份能量、回收目标或减免重复使用。刚登场成员不能立即被普通换手；其离场后空位的后续登场须按新窗口合法候选确认。未知抽牌或堆牌收益只记为机会，不能支撑确定的预算。

即使当前单张 LIVE 有机会唱成，仍应检查这条路线能否准备更高分或多张 LIVE、改善本轮可靠性，或在平局后保留更好的场面。单张需求达标不等于赢得分数比较；双方已有两张成功 LIVE 时，尤其要比较避免平局的加分/多 LIVE 路线。多 LIVE 必须合计修正后的逐色与总需求，不能逐张各算一次同一批 HEART。若回收后无预算、无合法后续或得不偿失，应保留成员；不要只为花能量、抽换同一张牌或维持循环而反复自送。

## 结束主要阶段前的比较

候选 activation 列出已查询的费用、去向和可见目标，entryResources 只覆盖部分登场条件；缺少后续摘要不表示卡文没有收益。直接从休息室登场只支付能力指定的费用，成员先回手再登场则需另一个合法登场机会和预算；回收 LIVE 则用于后续合法设置。当前只提交所选路线的第一步，之后按新状态与新候选继续，不复用旧引用或把整段计划当作已完成。

结束前比较最佳可见发展路线，包括上述自送回收路线。tradeoff 用简短结果说明该路线的关键回收目标/登场位置、净支付与用途，以及为何继续或放弃；不必复述全部候选或逐步推理。“场上已满”“现在能唱”“留到下回合”本身都不足以解释停止。保留能量须指明下次恢复前实际在场来源可支付的能力，并只预留所需数量；留在手里的能力成员不能充当当前保留能量的理由。不能为已完成或不再可行的计划一直留牌，有本回合可执行的用途就重新比较。本回合没有更有价值的路线时可以结束，不要求花光能量。
