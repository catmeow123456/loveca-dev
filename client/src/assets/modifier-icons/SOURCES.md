# 橙判心图标

`blade_heart_orange.png` 用于卡文 token `[オレンジブレード]`；普通橙心仍使用 `heart_orange.png`。

- 图案依据：[官方 BP08 预告](https://llofficial-cardgame.com/news/cdbj/)中的[橙判心介绍图](https://llofficial-cardgame.com/wordpress/wp-content/uploads/2026/08/06193113/21_BP08_5.png)。
- 制作日期：2026-11-10。未找到官方独立透明 PNG，使用内置 imagegen 从预告右下角提取并整理，再缩为 160 × 160；这是基于官方图案的派生素材，不是官方原始图标文件。
- 提取要求：仅保留橙色 L 心形、两枚黄色闪光及右侧粉蓝 BLADE，保留颜色、轮廓、白边、渐变和相对位置，去除背景及外部投影，输出透明 PNG。
- 后续若取得官方独立素材，可在保持文件名及 token 映射的前提下替换。
