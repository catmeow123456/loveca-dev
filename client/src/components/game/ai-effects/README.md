# 10 费宫下爱：把爱分给你♡

`PL!N-bp8-005` 费用10「宫下爱」全罕度共用专属反馈。视觉取自SEC的小恶魔红黑服装、短翼与角色分享心意的意象；没有额外人物登场或音效。立体红心、带翼膜筋线的短翼由SVG/CSS绘制并随正式客户端构建，最后的加心提示使用既有 `heart_red.png` 标准图标。

## 实际链路

- 常时加心由projector从权威公开 `TARGET_MEMBER` HEART贡献派生 `aiHeartLinks`，仅包含公开来源对象与双方舞台实例生命周期。己方虹咲（含爱）及对方所有成员各获一份，不发给己方其他团或下方卡。客户端只对新贡献播放约740ms的分享，待普通落场释放遮挡后开始；后来登场的成员只播放自身收到的那一份。来源或受益者离场立即撤掉对应反馈。没有新增持久规则状态、卡效暂停、ACK或操作屏蔽。
- 起动仍使用原[E]、叠能量、候选选择与双方公开确认。选牌期间不播放短翼爱心，费用由原能量移动反馈；选牌面板上沿为静态红黑缎带与短翼扣饰，独占一行避开标题和隐藏按钮；候选悬停、键盘聚焦及公开选中的卡采用暗红描边。结构与操作保持通用版本，不播放选牌前的爱心，也不增加确认步骤。
- 原公开确认结束、实际休息室→手牌移动成功后，`BattleAnimationLayer`给这一次普通回收事件附加邀请表现，替换普通回收画法，约940ms。短翼红心从爱飞到休息室，卡牌轻倾并直接飞进真实手牌。共用回收队列、遮挡和完成清理，不再返回休息室，也不新增规则等待。
- 归因要求前一份权威投影是本卡起动的已公开单选确认，公开目标确实离开休息室且手牌数量增加。前端不重算虹咲资格，不把任意回收当作爱起动。其他卡取得爱的能力时仍用普通回收。
- 对手仅临时使用此前已公开卡面，飞到匿名手牌区前淡为牌背，不关联或传出隐藏手牌对象。重新加载、切视角、撤销时间线或重开特效不会重播已有分享；观战/回放/教程/文字模式不增加专属演出。减少动态改为短暂标准加心提示及普通回收脉冲。动画中再次移动回收卡时，真实手牌不存在即立即收尾。

## 预览和素材

`http://127.0.0.1:5193/?ai` 仍是实际GameBoard与内存GameSession，可拖爱到中间舞台（能量卡组2张，手牌费用12），点击爱发动起动并实际选择休息室成员。工具栏“重置 · 自主登场”“重置 · 起动回手”分别重建可重复测试的起点，另有R罕度、无目标、减少动态。规则模式保留每回合一次；连续观察用重置或自由移牌。`?ai&ready&rare`直接看R罕度起动，`?inspect`、`?lock`、`?izumi`、`?protect`保留前两张卡预览。

夹具卡文来自用户指定 `references/cards_export_2026-10-29.json`，仅收录爱SEC、2费近江彼方、4费天王寺璃奈及原夹具所需牌。三张PNG由该导出的公开 `imageSourceUri` 对应对象取得，未重绘，保留原比例。R预览使用SEC图但规则编号为R；正式对局始终使用各卡自己的图片服务。它们仅是预览牌图，专属动画本身不依赖预览资源路径。

已接入共享正常对局源码，当前分享、邀请回手与红黑选牌装饰版本已获用户确认；尚未部署或进行真实账号双设备验收。验证见 `ai-animation-projection.test.ts`、原爱的卡效测试与 `client/dev/seras/ai.spec.ts`：全罕度公开范围、离场、已确认回收、对手隐藏手牌、真实拖牌/起动、一次付费、后入场成员、开关、快照、窄屏与减少动态；共用回收及赛拉丝/泉用相应回归覆盖。
