# 22 费穗乃果「回忆舞台」LIVE 专属演出

`PL!-pb2-001` 费用 22「高坂穗乃果」按基础编号覆盖全部罕度，已实测 R、PP。原有 R 素材人物登场、共用落场和登记保持不变；本目录不加载新的 PP 人物素材，没有新增音效。

`HonokaMemoryStage` 是可拖动时间进度的展示组件，只接收公开卡面、目标矩形和已经结算的收益。它不读取规则状态、不选择回收目标、不授予修正、不发游戏命令。成功卡以半透明投影展开，实体仍在成功区；底部不再绘制舞台、台阶和脚灯。分数与 ALL 心在卡牌上方同一行同时显现、停留和淡出，单项收益居中；直接复用 CardEffectText 的分数 token 与 modifier-icons/heart_all.png，不重绘规则图标。650–1030ms 在实际获得分数或心时，来源成员卡边出现一次轻微暖橙光；卡面投影和收益随后共同淡出。窄屏按可用垂直空间缩小回忆投影，避免与收益条重叠。回收选牌完成之后，实际所选卡经过独立的小舞台通道回手。成员卡、LIVE 卡分别保持原始纵横比例。

收益段 1400ms，选牌后的回收段 1000ms；两段之间完全交还原有效果选牌。减少动态为 420ms 的静态标准收益提示，不绘制舞台及卡面投影。公共牌面不能解析时不补读隐藏身份。

已接入真实对局的共享 `CardEntranceLayer`，沿用现有正式联机、对墙打与 DEBUG 范围及「对战特效」开关；教程、AI 调试、观战和回放不启用。规则依据用户指定的 `references/cards_export_2026-10-21.json`，未改三个图标的资格判断或收益规则。成功区可包含成员；DRAW 图标执行 μ’s 卡回收，绝不表现成抽卡。

权威 workflow 在加分／加心成功后创建 `entranceRuntime.pending.honokaMemory`；回收选择保持原 `activeEffect`，共享屏障阻止提前提交，动画结束才交还选牌。所选卡完成原有公开确认与实际回收后创建第二个窗口。公开投影只携带来源、成功区对象、实际收益和此前公开的回收卡快照，不读取隐藏手牌。`resumePendingEffects` 仅保存在权威侧，ACK／超时后消费一次并按原有顺序继续待处理效果，双方投影不包含此续接字段。

复用双方 ACK、单操作者确认、6 秒截止、旧 token 隔离与重连当前窗口机制，不补播已结束历史。播放器遇到缺失素材（预解码上限 2 秒）、目标失效、尺寸或滚动变化时结束本方演出；跳过、关闭或卸载释放回收移动遮挡。回收对象通过共用 `suppressDefaultMovement` 接管普通回手动画；对手回手落点只使用公开手牌区域。远端来源的展示朝桌面中央放置，避免顶部拥挤。减少动态不预加载飞牌、不建立遮挡。

5186 的本地内存测试页已改用正式共享播放器；`live-preview-events.ts` 只记录当前公开投影供手动重播，不再监听权威 actionHistory 或代理规则。回看速度、进度和循环只影响重播。`?reduced=1` 是 Vite 夹具内的确定性减少动态模拟，正式页面读取系统偏好。
