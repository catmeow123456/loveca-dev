# 璃奈专属演出

费用15「天王寺璃奈」`PL!N-bp8-009` 按基础编号覆盖全罕度；目录名 `rina-sec` 记录 SEC 插画来源，不是罕度限制。`RinaSecPresentation` 和 `rinaSecDrawing` 保留已确认的原型画面，由正式 `CardEntranceLayer` 接入，也供仓库外 5185 预览复用。

- 登场约3.38秒：璃奈板点阵表情、人物展示与姓名、完整实际印刷卡面落向真实槽位。复用已有 SEC 透明重绘及眨眼图，不新增人物素材；去字和遮挡重建仍属于重绘。资源准备、取消与完成计时沿用 `CardEntrancePlayback`。
- 换曲分两段：旧曲1.14秒，粉色三层空心点阵波纹发出后完整收回；新曲1.38秒，青绿波纹发出后完整入场，卡边和璃奈板同步亮两拍，再显示笑脸。两段之间保留实际玩家选牌，不预先展示休息室的未选卡。
- 减少动态只做短角标，换曲240ms、登场沿用共用短展示；不飞行，不创建人物 WebGL。无新增音效或开关。

规则工作流只在成功移动后的原子边界生成 `rinaLiveSwap` 公开快照，包含当前璃奈、被移动的公开 LIVE 卡面、所属席位、方向和实际 LIVE 索引。已离场或不同生命周期的璃奈不再发出视觉指令，原效果仍照常结算；无效选择、非 LIVE 费用、不成功的移动不播放。卡组隐藏内容和顺序不参与前端判断。

两段复用 `match.entrance`、双方 ACK、6秒上限、单操作者模式、撤销代际和权威超时。旧曲返回后暂缓下一选择；新曲入场后保存原工作流的继续策略，双方完成后消费一次，再结算新 LIVE 的自动效果及后续队列。`GameBoard` 复用既有弹窗/交互等待，通用移动播放器让出该对象；结束、跳过、关闭特效、资源失败、来源失效、滚动或尺寸变化均释放遮挡。重连仅处理仍在等待的实例，不补播已结束历史。

模式与开关沿用共用登场策略：正式联机、对墙打、本地及远程 DEBUG；教程、AI 调试、观战和回放不启用。5185 的自由测试直接使用正式播放器；独立重播工具仍在仓库外，不进入玩家页面。
