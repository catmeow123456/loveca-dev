# 本地卡牌登场试作

只在 Vite 开发模式、localhost/127.0.0.1 的本地双人调试、对墙打和 DEBUG 会话启用；只读回放/观战不启用。生产构建通过 DEV 分支排除动态模块。没有规则或服务器协议修改。

## 本地验证

1. 打开 http://localhost:5173/ ，照常选择自己的卡组进入本地对局。右上角夜间模式旁的「登场动画」开关默认开启：高亮星光图标和状态点表示开启，灰色斜杠表示关闭；桌面与窄屏共用状态。
2. 固定使用已确认的居中布局：人物主体居中略偏上，下方只展示卡名。已移除临时布局选择和预览栏。
3. 让费用 17「近江彼方」（PL!N-bp7-006，任意罕度）、费用 20「叶月恋」（PL!SP-pb2-005，含 R／PP）或费用 17「若菜四季」（PL!SP-pb2-008，含 R／PP）成功登场。普通付费或调试自由登场均从同一公共进场事件触发。
4. 演出持续约 2.74 秒：人物入场 0.6 秒，展示到第 1.5 秒，用 0.45 秒淡出；完整卡牌从第 1.75 秒开始，先用约 400ms 从画面中央飞到对应舞台位置，再用 150ms 以俯视桌面的视角压向桌面（最后压落时中心不移动，以尺寸和倾斜表现高度），与人物淡出略有重叠。落地前阴影收紧，触地闪光后停顿约 40ms，再以落点中心向四周平面扩散紫色光环和少量碎光，并短促轻震场地（背景、成员区和 LIVE 区，手牌与操作栏保持稳定）；其他场上成员和 LIVE 卡按与落点的距离轻微放大、倾斜并柔化阴影，随后恢复贴桌状态，不做屏幕向上位移，落场来源自身不弹起，可点「跳过演出」或关闭右上角「登场动画」。
5. 测试付费失败、起动能力、舞台位置移动时不播放；重复公开事件不重复播，离场后重新登场可重播。
6. 核对双方视角、连续登场、选择弹窗出现、窄屏及减少动态。减少动态时沿用约 160ms 的短展示，不执行卡牌下落与震动。

演出不参与状态推进，不增加任何规则等待。效果选择、费用支付、特殊登场步骤或结束状态出现时直接清空；最多暂存 4 次进场，等待超过 5 秒丢弃。首次载入、公共事件 epoch 变化、序号回退和切换对局都跳过历史。图片失败、WebGL 不可用或丢失时直接结束演出。落场期间改变窗口大小或滚动时中止，避免飞向过期坐标；来源离场、换位或方向变化时取消原演出。

落场复用公开对象定位、卡图路径及 `battleAnimationOcclusions`。专属演出以 `suppressDefaultMovement` 声明移动所有权，通用卡牌移动层让出该对象，避免重复飞牌；接触落点时释放遮挡并交还真实卡牌。跳过、关闭开关、重置或卸载都会释放本演出的遮挡，规则状态无需等待动画。

开关仅控制专属登场演出，不影响普通卡牌移动。当前桌面内保留选择，重新进入默认开启，不写账号设置。

## 角色配置

`cardEntranceProfiles.ts` 是事件过滤与舞台目标查询共用的基础编号映射，按当前队列条目传递卡名、居中取景、光晕与网格区域。`CardEntrancePortrait.tsx` 共用人物绘制与淡出；播放、取消、飞牌和遮挡仍只有一套。彼方与恋参数保留原值。四季使用青绿色人物光晕，短发两侧末端和腰间外套下摆轻微形变；新增可选 `rightHair` UV 区域，缺省时不改变旧角色的左侧发束算法。脸与伸手区域避开局部发束／衣摆遮罩，身体跟随幅度独立减小。三张卡共用约 2.74 秒时间线、紫色平面落地圈及取消／遮挡机制。

## 素材与局限

`kanata.png` 基于[官方 PL!N-bp7-E02-SECE 卡面](https://llofficial-cardgame.com/cardlist/searchresults/?cardno=PL!N-bp7-E02-SECE)的取景经 imagegen 重绘，用于本地概念验证，并非官方无字原画。没有补腿脚，人物服饰细节与官方原画仍有差异。仅用局部网格形变表现发束和衣料跟随，没有真正转身、眨眼或逐帧角色动作。

正式开放前仍需确认美术还原、遮挡、时长和移动端表现。

`ren.png` 基于[官方 PL!SP-pb2-005-PP 卡面](https://llofficial-cardgame.com/cardlist/searchresults/?cardno=PL!SP-pb2-005-PP)经 imagegen 去框、去字及透明背景重绘，保留原图截断的手臂与腿部范围；并非官方无字图，脸、手指与格纹细节可能存在重建差异。用户已确认此版素材。原图、提示词和独立预览保存在仓库外 `animation-prototypes/ren/`，运行时不依赖该目录。


`shiki.png` 基于[官方 PL!SP-pb2-008-PP 卡面](https://llofficial-cardgame.com/cardlist/searchresults/?cardno=PL!SP-pb2-008-PP)使用内置 imagegen 透明背景重绘。规则身份来自用户指定 `references/cards_export_2026-09-29.json`：基础编号 PL!SP-pb2-008、费用 17「若菜四季」、R／PP；PP 是人物素材来源，两个罕度均触发自身完整卡牌飞行。源卡只展示到大腿上缘，本版保留该范围，没有补腿脚。去掉卡框、背景、签名、SAMPLE 与图标；遮挡的手指、胸前饰物、格纹和腰部衣料经过重建，线条、比例、饰物不保证与原画完全一致，不是官方无字图。仅为网格微动，不含眨眼、转身或骨骼动作。原图、生成结果、完整提示词及隔离验收页保存在仓库外 `animation-prototypes/shiki/`，运行时仅依赖本目录 `shiki.png`。

- 浏览器使用仓库外隔离内存会话，导入真实 `GameBoard`、store、GameSession 和命令。测试夹具只准备舞台前状态；进场、回手、横置均走真实命令，不伪造播放事件，不访问账号或生产 API。
- 1600×900、390×844 人物与最终槽位已截图检查；完整卡牌飞行、桌面对手公开落点、平面冲击圈、结束后真卡恢复已实测。关闭再开启不补播；方向变化取消并保留横置；跳过四季后恋接续不串图；彼方可继续演出。三张场上卡结束时 `visibility=visible`、`transform=none`、`filter=none`，无遗留邻卡形变。窄屏未渲染对方舞台时按既有策略取消飞牌。
