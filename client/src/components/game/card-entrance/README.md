# 本地彼方登场试作

只在 Vite 开发模式、localhost/127.0.0.1 的本地双人调试、对墙打和 DEBUG 会话启用；只读回放/观战不启用。生产构建通过 DEV 分支排除动态模块。没有规则或服务器协议修改。

## 本地验证

1. 打开 http://localhost:5173/?summonAnimation=1 ，照常选择自己的卡组进入本地对局。也可在桌面顶部勾选「彼方登场试作」。
2. 默认使用「居中布局」：人物主体居中略偏上，下方只展示卡名；可切换「左右布局」对比旧版。点「预览」只播放当前视觉，不移动卡牌或改变对局状态。
3. 让费用 17「近江彼方」（PL!N-bp7-006，任意罕度）成功登场。普通付费或调试自由登场均从同一公共进场事件触发。
4. 演出持续约 2.4 秒，可点「跳过演出」或取消顶部勾选。勾选状态仅存在当前桌面，不写账号设置。
5. 测试付费失败、起动能力、舞台位置移动时不播放；重复公开事件不重复播，离场后重新登场可重播。
6. 核对双方视角、连续登场、选择弹窗出现、窄屏及减少动态。正式扩展前仍需单独验收窄屏表现。

演出不参与状态推进，不增加任何规则等待。效果选择、费用支付、特殊登场步骤或结束状态出现时直接清空；最多暂存 4 次进场，等待超过 5 秒丢弃。首次载入、公共事件 epoch 变化、序号回退和切换对局都跳过历史。图片失败、WebGL 不可用或丢失时直接结束演出。

## 素材与局限

`kanata.png` 基于[官方 PL!N-bp7-E02-SECE 卡面](https://llofficial-cardgame.com/cardlist/searchresults/?cardno=PL!N-bp7-E02-SECE)的取景经 imagegen 重绘，用于本地概念验证，并非官方无字原画。没有补腿脚，人物服饰细节与官方原画仍有差异。仅用局部网格形变表现发束和衣料跟随，没有真正转身、眨眼或逐帧角色动作。

正式开放前仍需确认美术还原、遮挡、时长和移动端表现。
