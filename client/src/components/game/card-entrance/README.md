# 卡牌登场演出

生产构建包含登场模块，正式联机、对墙打、本地及远程 DEBUG 桌面启用；教程、AI 调试、只读回放与观战不启用。联机采用服务器权威的双方演出等待，详见[作者部署与验收说明](../../../../../docs/card-entrance-production-rollout.md)。代码已接入不代表生产已部署。

## 本地验证

1. 打开 http://localhost:5173/ ，照常选择自己的卡组进入本地对局。右上角夜间模式旁的「登场动画」开关默认开启：高亮星光图标和状态点表示开启，灰色斜杠表示关闭；桌面与窄屏共用状态。
2. 固定使用已确认的居中布局：人物主体居中略偏上，下方只展示卡名。已移除临时布局选择和预览栏。
3. 让费用 17「近江彼方」（PL!N-bp7-006，任意罕度）、费用 20「叶月恋」（PL!SP-pb2-005，含 R／PP）、费用 17「若菜四季」（PL!SP-pb2-008，含 R／PP）、费用 20「渡边曜&鬼冢夏美&大泽瑠璃乃」（LL-bp2-001，R+）、费用 15「安养寺姬芽」（PL!HS-sd1-006，SD）、费用 15「钟岚珠」（PL!N-bp1-012，P／P+／R+／SEC）、费用 15「绚濑绘里」（PL!-pb2-020，N）或费用 22「高坂穗乃果」（PL!-pb2-001，R／PP）成功登场。普通付费或调试自由登场均从同一公共进场事件触发。
4. 演出持续约 2.74 秒：人物入场 0.6 秒，展示到第 1.5 秒，用 0.45 秒淡出；完整卡牌从第 1.75 秒开始，先用约 400ms 从画面中央飞到对应舞台位置，再用 150ms 以俯视桌面的视角压向桌面（最后压落时中心不移动，以尺寸和倾斜表现高度），与人物淡出略有重叠。落地前阴影收紧，触地闪光与场地冲量同步，以落点中心向四周平面扩散紫色光环和少量碎光，并在 210ms 内强起、快速衰减地震动场地（背景、成员区和 LIVE 区，手牌与操作栏保持稳定）；其他场上成员和 LIVE 卡按与落点的距离衰减冲量，根据落点与邻卡的屏幕相对位置，让朝向落点的一侧先翘起、背向落点的一侧作支点；方向会转换到卡牌自身坐标，横置卡也保持正确受力方向，独立平面阴影留在桌面上；每张公开对象具有稳定的幅度和回落节奏差异，支点与倾斜轴不随机，传播延迟最多 75ms；回落时先接触一条边，再让剩余翘起的一侧贴回桌面，临时阴影在完成或取消时移除，不做屏幕向上位移，落场来源自身不弹起，可点「跳过演出」。演出期间其他桌面操作锁定，开关在可操作时调整。
5. 测试付费失败、起动能力、舞台位置移动时不播放；重复公开事件不重复播，离场后重新登场可重播。
6. 核对双方视角、连续登场、选择弹窗出现、窄屏及减少动态。减少动态时沿用约 160ms 的短展示，不执行卡牌下落与震动。

合法登场及费用支付是一个完整动作；接着服务器在检查时机暂停后续卡效，投影 `match.entrance`（实例 ID、公开对象、等待席位、截止时间）。同一原子效果步骤不拆开，步骤内产生的登场在下一可安全暂停点演出；不回滚已付费用、不重复触发能力。客户端不自行结算规则。双方完成／跳过／关闭动画后各提交一次 `ACK_CARD_ENTRANCE`；另一方尚未完成时显示等待提示。首次进入页面只处理当前权威演出，不回放已结束的历史事件。撤销重做产生新实例，旧完成消息不能释放新等待。

单卡演出仍为 2.74 秒，素材准备上限 2 秒。服务器每张卡给 6 秒的总等待预算，多卡按本次公开登场卡数累计；独立计时器到期继续结算，快照轮询和维护扫描亦可兜底。不能靠客户端卡住或重复确认延长期限。等待时暂停排位操作计时，后续公共结果展示在恢复后取得完整阅读时间。认输／终局可直接退出。本地、远程 DEBUG 和对墙打由一个实际操作者确认，正式联机须两席确认。

落场复用公开对象定位、卡图路径及 `battleAnimationOcclusions`。专属演出以 `suppressDefaultMovement` 声明移动所有权，通用卡牌移动层让出该对象；触地释放遮挡并交还真实卡牌。跳过、图片／WebGL 失败、失效落点、窗口尺寸或滚动改变、卸载均释放遮挡；技术失败也确认本方结束，不能无限阻塞对局。减少动态只做短展示，不创建飞牌、冲击或邻卡动作。

开关只控制专属登场演出，不影响普通移牌。默认开启，使用本机当前站点的 localStorage 记忆；不修改账号设置。一方关闭时会立即确认本方结束，但仍等待另一方；双方关闭时仅需确认往返，不运行素材准备。

## 登记、时间线与加载

基础编号唯一维护在共享 `src/shared/card-entrance.ts` 的 `entranceCards`，服务器与客户端共用；`cardEntranceProfiles.ts` 引用它来绑定角色名、取景、光晕、网格区域与 `loadArt`，不复制卡号字符串。登记测试同时检查两层覆盖一致、重复 ID／基础编号及素材可解析。新增卡牌要同步共享身份、完整美术配置、上方清单和真实登场测试；不复制控制器。

`cardEntranceTimeline.ts` 统一以毫秒声明人物入场／淡出、标签、重叠、飞行／压落和冲击阶段，推导结束时间并生成光圈 CSS 时长。`CardEntrancePlayback` 在资源就绪后创建一次开始时刻，人物、飞牌和结束计时共用它。当前演出仍为 2.74 秒；逐卡美术调整不改变共用阶段时长。

素材按当前播放条目加载，不在进入对局时下载全部人物图。人物图与完整卡面都完成 `decode()` 后才启动时间线；减少动态仅准备人物图。准备最多等待 2 秒，失败或超时跳过当前条目并释放遮挡。关闭、跳过或来源失效会取消准备，迟到的导入／解码结果不能重启演出。动态导入不能撤回已经发出的网络请求，但取消后不会再创建画面。应用不保留所有角色的解码位图缓存，URL 缓存由浏览器管理。当前批次按权威 `objectIds` 依次播放，不再按 5 秒队龄丢弃后续卡；整批截止时间由服务器控制。
