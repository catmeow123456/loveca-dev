# 9 费桂城泉：白花守护

`PL!HS-bp8-008` 费用9「桂城泉」全罕度常时保护的公开状态反馈。己方顶层舞台有赛拉丝时，泉卡面右下角的白玫瑰约460ms展开，随后保留银白叶片与3.6秒周期的微弱呼吸光；条件消失约200ms淡出。白花不是通用免疫：仅表示此泉不会因对方卡牌效果变为待机，自身效果、费用及普通横置仍依原规则。泉和赛拉丝横置均不解除条件。没有月亮、人物重绘、音效或外部素材，SVG与CSS随客户端构建。

规则结算与projector共用 `hasIzumiOpponentWaitProtection`，只给公开顶层成员派生 `opponentWaitProtection: IZUMI_EDELNOTE`；不保存新规则状态，不向私密区域、下方成员、其他版本的泉或其他来源的待机保护误发标记。对方也能看见有效标记，终局移除。

`PlayerArea`卡面与`GameBoard`拖拽覆盖层共用`IzumiProtection`，随卡牌方向及拖动；不拦截指针，不产生ACK、服务器期限或操作等待。新到场泉的展开等普通飞牌释放遮挡后开始。加载已有快照、重连、切视角或重新打开特效均直接加入静态状态。减少动态只保留静态白花；关闭对战特效、纯文字和不支持演出的模式沿用赛拉丝锁链门禁。解除时公开状态立即消失，余下淡出仅为装饰，快速恢复条件会取消旧淡出。

## 可操作预览

打开 `http://127.0.0.1:5193/?protect`，点“赛拉丝入场 · 开启保护”／“赛拉丝离场 · 解除保护”可反复观察，也可自主拖牌。这个专门夹具使用空牌库与休息室、会话无人物演出设置，让赛拉丝实际登场命令完成后无牌可检视；不更改正式人物登场或检视流程。测试选项可检查R罕度、对手视角及减少动态。`?lock&active`验证已有场面直接显示标记，`?izumi`仍保留起动与返场的完整流程。

已接入共享正常对局代码，当前白玫瑰版本已获用户确认，尚未部署或进行真实账号双设备联机验收。`izumi-protection-projection.test.ts`验证双方投影、全罕度、方向、离场、下方卡、终局与其他保护来源；原9泉及果南待机保护测试覆盖实际动作门禁。`client/dev/seras/protection.spec.ts`使用内存GameSession验证真实命令、开关、减少动态、窄屏、拖牌、初始快照及解除／重新获得的过程。
