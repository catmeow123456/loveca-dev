# 13 费赛拉丝：幕间选曲与玫瑰链扣

`PL!HS-bp8-007` 全罕度登场检视与常时封锁的专属外观，入口位于正常 `GameBoard` 效果窗口和 `PlayerArea` 成员槽位，独立预览只负责准备初始牌局。没有新增持久规则字段、选牌资格判断或等待屏障；泉与宫下爱的专属动画不在本次范围。

- 仅匹配原卡的登场能力和检视步骤，以及该能力产生的公共 reveal dwell。吟子获得此能力时不会误用赛拉丝外观。
- 检视卡、可选卡和正面信息全部来自当前玩家投影。己方可以查看全部五张检视牌及详情；对手只有等待提示。公开步骤只使用 `revealedObjectIds`。
- 点击、跳过、隐藏、详情及自动继续使用原有 GameBoard 回调。空候选和放弃不播放公开收尾；仍按正常规则结算。
- 帷幕由中央向两侧展开约 650 ms，文字与卡牌在展开后段显现；每次新的检视重新开幕。公开卡的立体展示约 800 ms，包含在原有公共展示时间内，不增加卡效等待；重连/重新展开根据剩余展示时间定位公开卡的姿态。
- 上方保留帷幕与金边，两侧帷幕收进内容外的留白并向下渐隐；背景单独柔化边缘，文字和卡牌保持完全可见。面具斜挂于右上方，已撤掉下方弓弦和漂浮花瓣装饰。
- SVG 面具与帷幕随源码构建，没有额外下载的演出素材；卡面使用标准 `Card` 和投影图片路径。LIVE 保持横向 1.4:1。窄屏采用双列滚动，操作按钮固定在窗口底部。
- 沿用现有动画开关与模式政策；关闭动画或文字模式使用通用窗口，减少动态时保留静态主题和所有操作。不增加音效。

## 常时封锁

- `getStageMemberActivatedAbilityProhibition` 与原布尔门禁共用同一查询。projector 通过 `getStageMemberActivatedAbilityProhibitionForView`，仅向实际拥有原生或当前授予的舞台起动能力、且受到禁止的公开顶层成员投影 `activatedAbilityProhibition: SERAS_LOW_COST`。按能力持有情况筛选，不依赖被禁止后为空的可用按钮列表；没有起动能力的低费成员不显示锁链。规则门禁保持原义，不包含私密卡或新的持久状态；前端不重新判断费用、罕度、泉的身份或方向。
- 条件成立时，两段暗银锁链横跨卡面，在距卡底约四分之一处交叉捆住；两侧绕入位置错开高度，正面与侧向链环交替，有独立的厚度、阴影与金属反光。中央交点与左右四个绕入点从扣合开始就固定在最终位置，中间链环沿相同交叉路径滑入，暗红玫瑰扣原位闭合并轻微回弹；约 560ms 完成后原尺寸保留，不再缩成角标或跳换位置。锁链附着于实际卡面，随横置、悬停与拖动一起变化。封锁段不使用面具、文字底框或可见标签；登场检视的悬挂面具保持不变。
- 持续标记只跟随当前投影：费用跨越4/5边界、泉横置或来源离场时立即更新；多个有效来源按权威查询处理。解除后起动可用性立即恢复，仅保留180ms不可交互、无状态语义的松扣退链收尾。过程中再次生效会取消旧收尾；换牌、切视角或关闭动画直接清除。无 ACK、额外结算等待或基于动画时长的规则续接。
- 受影响的新成员实际登场时，复用既有飞牌遮挡状态，等真实舞台卡面露出后再播放完整扣合，避免动画在隐藏卡面上提前耗尽。期间不新增操作锁、ACK或结算等待；来源在落场途中失效时取消待播扣合。已显示的静态标记不会因普通遮挡结束而重播。
- 初始载入、重新进入和切换视角直接显示已有标记，不补播。减少动态使用静态链扣，解除直接移除；关闭专属动画、文字模式和不支持专属演出的模式不显示链扣。已有起动合法性与按钮列表保持原路径，舞台保留封锁原因的文字提示。
- 标记不拦截鼠标或触摸；只挂在正常舞台卡面及其拖动预览，不出现在手牌、详情、检视副本或遮蔽卡上。SVG 随源码构建，无新下载素材或音效。

## 本地反复测试

在仓库根执行 `node client/node_modules/vite/bin/vite.js --config client/dev/seras/vite.config.mjs`，打开 `http://127.0.0.1:5193/`。拖手牌中的赛拉丝到舞台，或点“再次检视”通过实际登场命令直达选牌。工具栏可重置、切对手视角、验证无候选/R 罕度/减少动态。点“封锁测试”（或 `?lock`）准备自由模式下的双方舞台：己方2费穗乃果、对手4费泉显示锁链，9费泉与没有起动能力的4费花帆不显示。双击己方左侧泉或点“泉横置／转正”通过真实 TAP_MEMBER 命令反复开关；可拖走赛拉丝或泉、切规则模式核对起动限制。点“低费登场测试”（或 `?lock&entry`）准备已生效封锁、手牌4费泉和空出的右槽，直接拖入即可验证落场后扣合。`?lock&active` 验证载入已有封锁不补播。该页面使用内存 GameSession，屏蔽 `/api/`，不访问账号或后台；5193 不占用其他工作树端口。

卡牌数据来自授权的 `references/cards_export_2026-10-29.json`，测试页保存八张相关卡的快照与公开卡图；2费穗乃果、4费泉及4费花帆的图片从工作区既有公开卡图转换为 WebP。R 场景仅替换显示卡号，用于验证全罕度分流，不伪称导出中另有 R 卡图。
