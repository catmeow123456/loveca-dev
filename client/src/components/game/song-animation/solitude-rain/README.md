## 触发与续接

单卡 workflow 先验证目标舞台实例，完成原有固定 HEART 快照转换和当次分数判定，移除本项 pending，再生成 `EntranceWait.solitudeRain`。字段仅含来源 LIVE、真实目标、实际转换数量和实际加分。projector 转换为公开对象 ID；React 不检查紫心总数、重新统计红蓝或重算加分资格。源 LIVE 已离开时沿原规则完成独立成员转换，不合成歌曲演出；stale/no-target 不播放。有效 0 转换仅显示中性雨水收束，没有红蓝合色、紫心数值或加分。

规则先原子提交，演出期间暂停后续 pending。正常总长 1900ms：雨丝全程按各雨道的固定速度连续下落，收拢阶段不再减速、停住或重新启动；1300–1560ms 一边继续下落一边淡出。两束软边红蓝舞台光从 80–1380ms 持续向开放侧卡沿收拢，交集在卡沿内外逐渐扩大并呈现紫色；1260ms 开始淡出，衔接标准紫 HEART 数值，避免收拢前后的长时间静止。仅权威 `scoreBonus > 0` 时，1330–1520ms 最后一滴雨落到来源 LIVE，1520ms 标准分数数值。无装饰说明文字或音效，LIVE 比例和方向继续由公共卡牌组件控制。

复用 `CardEntranceLayer`、现有特效开关、模式许可、`useCardEntranceBarrier`、ACK/6 秒权威超时和一次性 `resumePendingEffects`。本地及对墙打一席确认；联机等待双方。自动顺序仍需选择每个目标，演出结束继续原批次，绝不重新结算。过期 ACK 被拒绝；恢复已结束窗口不补播。观战、历史回放和文字展示不扩展动画范围。

## 绘制与资源

`solitudeRainRenderer.ts` 使用透明 Canvas 2D，绘制局部环境明暗、十二条雨道中错开循环的三十六段雨丝、两束软边舞台灯与一次低亮度白色纸面反光。灯光由可复用的 160×224 离屏光场生成：两束光向卡面扩散，落点向卡沿中央移动，逐点求共同受光区域，仅交集为紫色。交集延伸到卡沿外较暗的区域，使用更饱和的紫罗兰色；合色后两侧红蓝逐渐减弱，在紫 HEART 出现前留下约 300ms 的清晰合色阶段，雨和光仍持续运动。雨丝在光场上方绘制，并沿每段雨丝采样同一交集，进入时染上紫光、离开时恢复原色。没有亮线或硬边光锥；卡面局部受光透明度上限约 34%，不将整张卡统一染色。环境和雨丝仍避开印刷卡面，真实卡牌始终可见，不复制、翻转、抬起或替换成员卡。没有水面、倒影、人物图、发射器或 WebGL 纹理。顶行目标改从下方开放区域照向卡面下沿，中央雨道随之放在同一开放侧，避免上方手牌干扰。光场只包含灯光，不读取卡图或回读 GPU；光场几何不变时复用已绘制的离屏纹理，淡出透明度在合成阶段处理；主画布像素密度上限 2 倍，结束清空画布。

正式演出仅额外预热通过正常构建导入的标准紫 HEART 图标，使用既有 `EffectImageCache`，首播等待解码至多 2 秒，失败、取消和迟到结果均收尾。分数使用共用标准反馈组件。没有预览专用素材地址、成员图片二次加载或跨源纹理要求。画面尺寸改变、目标失效或绘制上下文丢失时结束；减少动态或 Canvas 2D 不可用时，以 550ms 静态展示权威数值。真实图形上下文故障未人工注入。

共用 `EffectFeedbackLayer` 在 entrance 窗口消费并抑制同次反馈，不在 ACK 后补播。本曲复用其 `EffectFeedbackValue` 和标准 CSS 图标/数字，在时间线上各出现一次；真实目标的常驻修正徽标暂时隐藏至窗口结束，避免先出现最终紫心数值。原统计和规则状态不回滚或延迟修改；特效关闭、观战和回放保留常驻徽标及既有模式行为。
