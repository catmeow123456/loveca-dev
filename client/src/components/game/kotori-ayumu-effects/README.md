# 小鸟与步梦：心意赠礼

`PL!-bp8-003` 费用 4「南琴梨（南小鸟）」、`PL!N-bp8-001` 费用 2「上原步梦」的全罕度效果动画。已挂载共用 `GameBoard`，预览与正常对局使用相同绘制和触发组件；没有人物登场演出或声音。选择面板按实际移牌演出短暂延后开放；权威结算没有新增等待。已接入共用牌桌，尚未部署。

## 视觉与范围

- 小鸟「心意诊笺」：奶油色纱布双翼与细缝线直接附着在公开弃牌上；双翼展开、轻摆后随卡收拢，不再悬挂独立爱心，沿用原有 300ms 飞入、720ms 公开停留、160ms 收入休息室及退出淡出。随后开放检视。选中的卡带小羽翼共同飞入手牌（720ms），自己显示可见牌面，对手只看匿名卡背。弃牌与检视选择窗口使用默认界面，不附加边框装饰或选牌收线反馈。
- 步梦「猫铃的赠礼」：黑紫蝴蝶结、金铃和糖纸包着真实能量卡，沿侧下方弧线滑入实际接收成员下方（720ms）。飞行卡按真实成员轮廓裁切，接触成员时逐渐被遮挡，收尾与实体下方卡占用同一落点，不在结束帧切换层级。LIVE 成功回收时糖纸逐渐打开、能量落回能量区（680ms），抽牌随后飞入手牌（360ms），再开放原弃牌选择。只给自己／只给他人／双方各一张对应实际结果，不重复飞牌或抽牌。
- 小鸟常时「心意守候」：符合条件的己方待机 μ’s 成员卡角显示一枚淡粉爱心，光晕缓慢呼吸，表示与 μ’s 成员换手时减免值为自身有效费用加 1。包含待机小鸟自身；多张来源仍只显示一枚，来源全部离场、成员活跃／离场或对局结束时立即移除。字段由投影复用费用计算的同一判定派生，不创建持久状态，不改变费用；对手可见相同公开标记。加载／切视角只呈现当前状态，不补播形成动画；关闭特效隐藏，减少动态静态显示。
- 减少动态沿用静态公开弃牌展示（800ms）与目的地短亮边，随后开放选择，不做长距离飞行。弃牌双翼只随本次处理显示；常时爱心严格跟随当前条件。

角色参考：官方[小鸟介绍](https://lovelive-as.bushimo.jp/member/kotori/)提到裁缝与衣装支持，[步梦介绍](https://lovelive-as.bushimo.jp/member/ayumu/)强调踏实努力。护士诊笺、猫铃赠礼是结合本张卡面的创作意象，不是新增角色设定。

## 权威边界与可见性

`kotoriAyumuEffects.ts` 观察原有能力步骤前后的公开投影；`careMovementPresentation.ts` 把确认的移动交给共用 `BattleAnimationLayer`，不改 workflow、命令、费用原子性或权威状态，不添加 ACK。常时 `kotoriMuseRelayBonus` 复用 `hasKotoriWaitingMuseRelayBonus`，传递公开布尔值，不按来源数量渲染：

- 小鸟弃牌由原公共日志批次负责。检视阶段本来就在等待玩家选择，客户端只暂缓显示该步骤的选择面板和检视区；公开弃牌完成并退出后立即放行。公共日志晚到时仍匹配同一权威 seq 范围，缺日志最多等 2500ms；关闭特效、切换视角、重置或步骤变化都会解除本地遮挡。
- 选牌和抽牌图像只从本视角已有公开投影获取；对手载荷不含私密 ID／牌面，匿名卡背落定前暂隐一张终点卡背。能量卡及公开弃牌保留真实图像。装饰与卡牌是同一个移动对象，共用起点、终点和时间，不再叠加独立 Canvas 飞行。
- 步梦通过原步骤和能量区／舞台下方能量的实际移动确认结果，特殊能量尚在选择时不播放。回收后原有抽弃步骤已经等待输入，视觉按回收→抽牌→弃牌选择衔接；来源或目标移动、跳过和无效选择不伪造结果。
- 仅实际本编号舞台来源启用，其他角色借用能力继续普通反馈。复用既有开关和模式策略；首次快照、视角／对局切换、撤销重置、倒退序列、重新启用特效不补播。
- 程序 SVG/CSS 装饰，无额外素材加载或预览资源依赖。卡面由既有图片服务负责；完整图像比例保持 5:7，装饰不拦截输入。

## 可操作预览

启动 `client/dev/kotori-ayumu/vite.config.mjs`，地址 `http://127.0.0.1:5195/`。仅内存 `GameSession`，不连接账号、后端或数据库。正常拖牌、发动能力、能量选择和阶段操作都走共用 `GameBoard`。

底部切换「小鸟起动」「步梦下置」「步梦LIVE成功」。下置场景把步梦留在手牌，拖到中央后选择分配；LIVE 场景预置成功边界，由原有事件和 pending runner 生成队列，选步梦再选择成员／能量及弃牌。歌曲自己的成功效果仍按原队列继续。工具支持重置、重播、0.3 倍慢放、600ms 定格、R 罕度和减少动态。「双小鸟常时标记」预置两张活跃小鸟及一名待机 μ’s 成员，可正常换手验证：受益成员只有一枚爱心。手动镜头不改变规则。
