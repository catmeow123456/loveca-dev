## 维护边界

- 本目录保留公共牌桌一期的需求与设计背景，并描述尚未实现的匹配增强和天梯方向；当前房间返回、退出和恢复行为不在本目录重复维护。
- 当前联机能力与限制以 [联机模式准备文档](../online-mode/preparation.md)、[联机房间返回、退出与恢复设计](../online-mode/room-exit-and-recovery.md)和[当前实现限制](../current-limitations.md)为准。
- 公共牌桌一期的实现范围或验收边界变化时，应同步校对需求与设计草稿的状态说明；已经落地的房间交互事实以现行联机专题文档为准。
- 当前实际使用观察已经证明玩家愿意在公共牌桌统一入口持续候场，排位设计与基础实现可以进入下一阶段。公共牌桌尚未收束的故障恢复和指标仍需继续补强，其中会影响积分可信度、赛季暂停和异常结算的部分必须在首个排位 Beta 对玩家开放前完成。
- 首版排位采用独立赛季排位页和固定活跃时段，底层复用公共牌桌候场与正式联机房间；不把休闲公共牌桌改成默认计分入口。
