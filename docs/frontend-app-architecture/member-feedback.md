# 成员心／刀强化反馈

从 `feat/card-effect-feedback-next` 的 `c35b7970` 提取二维增益展示，接入当前共享 `GameBoard`。成员实际获得 HEART／BLADE 后，卡面出现斜向流光，对应图标与实际增量浮起后淡出；常驻加成标记继续由原投影展示。多目标并行，同一目标的混合种类、颜色与正负变化逐项保留。反馈最多 1250ms，不增加命令等待、不截获操作。

仅迁移成员心／刀及来源短提示，不引入三维舞台、旧回收、LIVE 分数／需求或能量／方向提示。当前登场、二维回收、起动的 1.5 倍速流光和 1000ms 浮起时序保持原实现。普通起动及支付费用本身不触发强化流光，真实增益生效后才播放。

## 事件与可见性

`src/online/effect-feedback.ts` 复用权威 modifier 与有效数值查询，从已完成的状态转换生成 `EffectFeedback` 公开事件；`GameSession` 负责发布。新增事件仅携带公开来源／目标对象 ID、区域、心色和实际增量。modifier 必须在前后状态都对双方可见，单纯公开或隐藏条件不伪装成增减。重复授予保留次数，刀数减至零时使用钳制后的实际变化；移除和持续条件变化使用较弱的 UPDATE。

事件不改变规则或权威状态，不显示在玩家公共日志和未读计数中。正式联机与本地使用同一条投影和展示路径；前端与共享/API 需一起发布，无新增数据库字段、贴图、第三方依赖或生产配置。

## 展示与清理

`EffectFeedbackLayer` 将流光挂到真实卡牌内，继承卡牌旋转、缩放；图标数值保持屏幕直立并跟随目标。新事件立即替换同一目标的旧反馈，不跨事件累加、不排队等待；不同目标可以同时展示。

窄屏下增益图标为 22px、数字为 18px，混合结果按目标卡宽换行，避免覆盖相邻成员；桌面保持旧版图标和数值大小。

首次进入只建立消费水位，不重播旧日志。切换对局／视角、撤销回退、公开展示 epoch 改变时重置。目标离开原区域、变为隐藏或 DOM 身份替换时立即结束。登场等待期间消费但不展示，观战和回放不播放。减少动态时仅保留约 220ms 的数值淡入淡出；最后一个反馈结束后停止逐帧采样。
