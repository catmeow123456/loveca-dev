# 二维休息室回收动画

共享 `GameBoard` / `PlayerArea` 的 `BattleAnimationLayer` 在真实投影出现 `WAITING_ROOM → HAND` 后播放。规则、结算、命令和公共展示期限保持作者主分支实现；不读取卡文推测回收成功。展示复用“放置入休息室”的布局、卡牌样式与运动曲线，并按反方向播放；只使用 DOM 与已有 Framer Motion，无 Three.js 依赖。

## 时间轴与落点

每张卡从休息室展开 160ms，在同一弃牌展示位置停留 720ms，再用 300ms 收入手牌，总计 1180ms；对应弃牌的 300ms 移入、720ms 展示、160ms 收拢顺序反转。同批多张同步展开到原弃牌扇形／网格位置，随后分别落入真实手牌；不显示“放置入休息室 ×几”或回收文字，不再使用蓄光、光束、拖尾。正反向共用 `waitingRoomCardPresentation.ts` 的几何关键帧、缓动及卡牌样式，布局复用 `getDiscardPresentationBatchLayout`。

费用13「米娅·泰勒」（PL!N-bp7-011，各罕度）完整沿用上述通用回收动画，不增加专属侧倾、亮边或弧线参数。它只等待弃掉的手牌进入休息室后再播放，与1.3秒休息室回卡组的特殊登场前段相互独立。

`recoveryCardMotion.ts` 提供纯时间轴采样及几何测量；`RecoveryCardMotion.tsx` 用一个帧回调更新反向轨迹。起点优先取当前牌堆锚点，避免展开的休息室选牌窗口成为起点。己方终点每帧测量 `data-recovery-hand-card` 内实际卡牌边界，反解扇形旋转后的宽高，保留祖先缩放；选择窗口收起、手牌重排或窗口尺寸变化不会沿用旧终点。终点姿态完整绘制一帧后交还真实手牌，避免反向加速曲线的最后一帧被移除；无退出缩放或淡出。

移动遮挡沿用统一事件时长与 120ms 兜底缓冲，并在组件完成／目标离开手牌时立即释放。减少动态沿用 120ms 区域提示，不隐藏真实手牌。公开选牌展示与公开弃牌展示保留原时长及各自队列，不缩短为回收动画时间。

`recoveryPresentationQueue.ts` 只延后视觉播放：等公开日志追平，且同一席位排队及正在播放的弃牌展示收拢、完成50ms退出后，再一起释放回收卡并按席位分组展开。等待期间遮挡真实手牌中的目的卡，防止它提前出现；公开日志未到达时也不会先播放回收。等待最多5秒，超时只取消动画并恢复手牌；切换对局／视角／时间线会清空待播项、计时器和遮挡。卡效和命令不等待此队列。一次弃牌接通用回收约2.4秒，弃牌正面和回收正面不重叠。

## 时间线与可见性

`battleAnimationHistory.ts` 只在同一前进时间线内去重；对局、座位、只读模式、公开演出 epoch 变化或 seq 回退时清空，并分配新的本地代际 ID。撤销不播放反向回收／弃牌，旧计时器、旧遮挡及退出子组件一起清理，旧完成回调无法命中同牌重做。待播回收不被无关前进状态更新吞掉；目标不再位于当前手牌时结束演出。

动画图片仍由既有投影正反面逻辑提供，组件不解析卡号、不读取对手私密数据。己方只跟踪已渲染的手牌节点；匿名背面只使用允许的公共区域终点，不为隐藏手牌建立对象映射。没有合法移动的无目标、跳过与非法命令均不生成成功回收。

## 本地验收与回归

[验收入口说明](../../client/tests/recovery-review/README.md)提供真实卡效局面和启动命令。页面仅加载共享 `GameBoard`，测试按钮只准备初始局面或调用真实命令；不连接账号、生产 API 或数据库。视觉是否达到认可标准由用户判断。

- `tests/unit/recovery-card-motion.test.ts`：正反轨迹一致性、阶段边界、静止展示、实时终点、扇形几何、同批同步、弃牌等待／日志补到／过期以及撤销去重。
- `tests/integration/recovery-animation.test.ts`：真实卡效回收 A → 撤销 → 同一 A 再回收，双张回收、公开展示期限、非法／无目标和对手隐藏投影。
- `client/tests/recovery-review/recovery.spec.ts`：原生选牌、完整遮挡时限、最终 DOM 边界误差、双张、窄屏变化、对局／视角取消、减少动态、悬停期间撤销后重做。逐帧采样避免固定等待与测试轮询错过短动画。

真实双客户端网络延迟和低端设备性能未单独实测。大批量移动沿用主分支现有超过 8 张时的区域提示降级；本次不扩展该策略。
