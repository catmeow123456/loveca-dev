# 海克斯第三批必要心与中央成员加成

> 文档类型：实现说明
> 适用范围：标准规则中的「小画家」「灵活单推」及本地双人调试
> 当前状态：两项效果已接入；后续真人选择流程见[联机海克斯](hextech-online.md)

## 效果口径

| 海克斯         | 已实现效果                                                                                                                                                                                         |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 小画家（彩）   | 己方每张 LIVE 的当前必要心中，已要求的每种彩色心各增加 1。印刷必要心含至少三种不同彩色的 LIVE，其灰心／万能心必要数量在其他增减修正后归零。没有要求的颜色不会凭空增加。                            |
| 灵活单推（彩） | 己方中央槽顶层成员按结构化团体身份获得加成：μ's 为粉／黄／紫心各 1，Aqours 为红／绿／蓝心各 1，Liella! 为红／黄／紫心各 1，蓮ノ空为粉／绿／蓝心各 1，虹ヶ咲为 4 棒。成员换位或离场后随即失去加成。 |

「灵活单推」按中央成员符合的团体逐项计算；跨团体成员同时符合多项时叠加对应加成。成员的心和棒作用在该成员上：待机时心仍参与 LIVE 判定，棒只在活跃时参与声援。团体身份沿用现有卡牌结构化识别。

「小画家」在共享必要心修正器中使用两项明确操作：完成普通增减后清零灰／万能心必要数量，并给仍有必要数量的每种彩色心加 1。因此其他效果新增的必要颜色也会受到加成。三色门槛由 LIVE 印刷的彩色必要心判定，不随同场效果增减改变。三色门槛外的 LIVE 仍会逐色加 1，但保留其灰心必要数量。

## 接入与验证

定义位于 `src/domain/hextech/catalog.ts`；`src/domain/hextech/modifiers.ts` 根据当前 LIVE 区、中央成员和持有实例生成修正，走既有实际判定、预览与舞台成员投影。必要心修正对未公开的 LIVE 区内容附带可见性限制，不向对手提前投影盖牌要求。效果来源保留海克斯实例身份，不借用成员卡作为来源，也不新增持久计数。

规则测试覆盖三色门槛、逐色增量、灰心归零与其他必要心修正的组合、实际 LIVE 成败、盖牌信息隔离、中央换位、各团体加成及跨团体叠加。浏览器测试覆盖本地配置、取得和持有说明的窄屏展示。

两项沿用[首批效果与本地测试](hextech-first-batch.md)的调试入口；此前三项条件加成见[第二批条件加成](hextech-second-batch.md)。随机候选与正式联机入口见[真人选择流程](hextech-online.md)。
