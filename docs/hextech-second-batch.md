# 海克斯第二批条件加成

> 文档类型：实现说明
> 适用范围：标准规则中的「你也是区」「团魂」「偏差认知」及本地双人调试
> 当前状态：三项条件加成已接入；后续真人选择流程见[联机海克斯](hextech-online.md)

## 条目与判定

本批以用户提供的海克斯工作簿为依据，继续使用 `HEXTECH_V1` 的持有状态、公开事件和本地调试入口。三项均按持有者实时生成修正，不增加额外的持久计数。

| 稀有度 | 海克斯   | 当前效果                                                                                        |
| ------ | -------- | ----------------------------------------------------------------------------------------------- |
| 银     | 你也是区 | 自己成功区每有 1 张卡，玩家获得 1 个万能心；卡牌移出成功区后随即减少。                          |
| 金     | 团魂     | 自己左、中、右三个舞台槽都有成员，且三人至少共享一个团体时，玩家获得 3 棒；待机成员仍属于舞台。 |
| 金     | 偏差认知 | 取得当回合额外声援 4 张，此后每经过一个回合减少 1 张，最低为 0；按各实例的取得回合独立计算。    |

「团魂」沿用卡牌的结构化团体身份，跨团体成员只要与另两人有共同团体即可满足条件。「偏差认知」修正的是实际声援公开数量，不增加成员或玩家的棒数；它与已有棒数及其他声援数量修正一起进入同一结算入口。「你也是区」的万能心属于玩家总量，不按每张 LIVE 重复授予。

## 接入与验证

条目目录在 `src/domain/hextech/catalog.ts`；持有关系由 `GameState.hextech` 保存，`src/domain/hextech/modifiers.ts` 读取当前成功区、舞台及回合状态，生成共享 LIVE 修正。双方完成换牌后可在“对局 → 双人调试 → 海克斯测试”指定本批条目；持有列表与公开日志沿用首批的投影路径。

规则测试覆盖成功区张数对实际 LIVE 成败的影响、与玩家加分的叠加、三人同团体及待机条件、声援实际公开数量、跨回合递减、后取得实例和 checkpoint 复水。浏览器检查新条目从配置到换牌后取得及双方公开展示；相关 UI 与模式边界见[首批效果与本地测试](hextech-first-batch.md)。

随机选择、重抽和联机接入已按[真人选择流程](hextech-online.md)实现。其他需要主动发动、双方选择或改写基础规则的条目仍未开放。
