# Loveca 海克斯玩法需求

> 文档类型：需求文档\
> 适用范围：海克斯娱乐对战的玩法规则、能力范围、玩家体验与验收要求\
> 当前状态：正式需求；首版范围已确定，后续扩展按条目裁定，开发验证与生产开放分别验收\
> 规则版本：`HEXTECH_V1`

## 目标与范围

海克斯玩法在标准 Loveca 对局中加入三次随机强化选择。玩家通过持续加成、取得收益与主动能力改变决策，但仍使用原有卡组、对局流程和共享规则。正式联机、本地双人调试、观战与历史回放必须遵守同一规则和信息权限。

首版作为独立的娱乐玩法，使用标准对局规则，不限制 PT；普通构筑的牌数、同名上限和胜利条件继续有效。首版不与开盒战组合，不包含排位、AI 海克斯决策、已持有海克斯的替换、额外舞台、任意能力响应和特殊胜利条件。

[原始策划工作簿](sources/hextech-design-source.xlsx)保留全部 125 项提案：银 41、金 42、彩 42；原文件名为 `haikesi.xlsx`，Sheet2、Sheet3 为空。工作簿用于追溯原始效果和名称；本文确定线上规则、首版范围及尚待裁定的边界。收录在工作簿或本文索引中不等于进入可抽取池。

首版开发基线已实现下文列出的 24 项，银 9、金 7、彩 8；其余 101 项属于扩展候选。实现与验证依据见[海克斯开发 PR #81](https://github.com/catmeow123456/loveca-dev/pull/81)及文末的实现说明。该开发基线不代表已合入主分支或已发布生产；本文的需求规则不依赖 PR 的合并状态。

## 基础规则与用语

一个回合包含双方各自的通常阶段及随后共同进行的 LIVE 阶段。通常阶段依次恢复活跃、补充能量、抽牌和进行主要操作。海克斯所说的“每回合”按这个完整回合计算，不按单个玩家的行动次数计算。

标准构筑包含 48 张成员、12 张 LIVE 和 12 张能量，开局手牌为 6 张、初始能量为 3 张。舞台为左、中、右三个成员区。成员下方的堆叠卡不自动成为独立舞台成员。

LIVE 判定必须区分心需求达成、最终比分、成功区放置资格和整局胜利。标准规则以成功区累计三张 LIVE 获胜；平分且已有两张成功 LIVE 时，不能依靠该次平局取得第三张。海克斯没有明确改变的部分继续遵守基础规则。

| 用语 | 规则含义 |
| --- | --- |
| 心、all、灰心 | all 指万能心，可补指定颜色；灰心只贡献总量。成员心、声援判心、LIVE 必要心分别计算。 |
| 棒、判 | 棒通常决定声援数量；判指卡牌的声援判定，可产生心、抽牌或加分。增加声援数量不等于增加棒数。 |
| 歌、成功区 | 歌指 LIVE 卡；成功区记录胜利进度。LIVE 成功不等于已取得放置资格或已进入成功区。 |
| 取得阶段 | 按取得时的回合确定：第 1–2 回合为第 1 轮，第 3–4 回合为第 2 轮，第 5 回合及以后为第 3 轮。 |
| 每回合一次 | 使用次数归属于具体持有实例。同名能力的多个实例分别计次。 |
| 跳费、回费、支付费用 | 分别涉及增加能量、恢复已有能量、消耗可用能量；须作用于真实能量卡，不能视为同一种数值增减。 |
| 储存能量 | 原始提案中的独立可消费资源，区别于能量卡数量和活跃能量；首版未开放。 |
| 炸、自爆、肘飞、扣置 | 原始提案的口语，必须先确定目的区域、费用属性、退场事实及恢复时点，才可成为线上规则。 |

## 选择、重抽与取得

### 选择时点

第 1、3、5 回合开始时，系统自动生成本轮共同稀有度及双方各三项候选，直接展示，不要求先攻或任何玩家点击随机按钮。

第 1 回合在双方完成换牌之后开启；第 3、5 回合在上一回合结算完毕之后开启。选择及取得后的选牌未完成时，暂停活跃恢复、通常抽牌和回合开始效果的处理，不允许通过其他操作推进对局；玩家仍可认输。

双方同时选择，没有先后顺序。每人可以重抽候选，再选择一项并确认；先确认的一方等待另一方，双方均确认后才取得能力并继续。锁定后不能更改，也不提前发放收益。

### 候选池与重抽

首版采用以下规则，后续概率和平衡调整需要明确修改规则口径：

- 银、金、彩各有 1/3 概率；同一轮双方使用相同稀有度。随机结果由权威端生成。
- 只从完整实现并经过对应验证的能力中抽取。每档至少包含三个不同条目，双方独立抽取，初始三项互不重复，不扣减共享库存。
- 每个候选位置可重抽一次；重抽后仍为同一稀有度。优先排除当前展示的三项；没有新条目时可以与其他位置重复，但不能抽回该位置原项。
- 重抽次数不跨轮保存，已持有能力不从后续候选中移除。后续轮次可以再次取得同名能力。
- 随机、重抽与确认不能撤销。重连、重复请求和恢复状态不能产生额外重抽机会。
- 首版沿用娱乐对局的等待与认输规则，不设置海克斯专用倒计时或超时默认选择。

### 取得顺序与公开范围

候选、重抽结果和本人锁定项只对本人可见；对手只看到确认进度，观战者只看到本轮稀有度与双方进度。双方确认后，在同一次权威提交中登记并公开双方持有，再按先攻顺序处理完整的取得效果。

需要选牌的取得效果暂停后续取得和回合流程，完成后继续。重连或恢复必须续办当前选择，不能重复弃牌、重新随机或再次给予取得收益。对手与观战者只能看到公开来源和等待方，不能取得私密检索候选或准确可选数量。

普通三轮选择通常取得三项，但额外取得可以增加持有数量，不能将持有上限固定为三。首次本地预设授予按第 1 轮处理；正式随机选择与本地预设是不同入口，同一局不能混用。

## 能力的共同规则

每个持有实例必须有独立身份和明确来源，能够区分持有者、定义、取得回合及使用次数。名称用于展示，不决定规则行为。同名持续加成和成长按实例叠加；“将判定设置为某结果”按替换语义处理，不因持有多份就重复产生判定。

取得收益与持续效果分开处理：取得时产生的抽牌、弃牌或区域移动只执行一次；持续加成随场面、区域和期限重新计算。恢复状态、跨阶段清理或再次查看能力均不能重发取得收益。已发生的收益不能因为持续条件消失而被回滚。

玩家总心、玩家总棒和合计分数不按舞台成员或 LIVE 张数重复授予。成员专属加成随该成员的位置和身份生效；成员待机时仍贡献心，但其棒通常不参与声援。实际判定、预览与玩家可见数值必须使用同一规则口径，印刷值与有效值需要能区分。

主动能力仅能由持有者在规定窗口使用。首版两项起动能力均在自己的主要阶段发动；存在尚未完成的能力或选牌时，不能插入新的海克斯发动。客户端选中目标不等于支付或使用能力，权威校验通过后才提交结果和消耗次数；非法输入不能造成部分支付或移动。

弃牌、待机和区域移动必须产生与实际结果一致的规则事实，相关卡效在当前效果完整处理后的合法检查时点继续。未来涉及瞬时条件时，必须记录结算中途真实发生的事实，不能只读取整条效果结束后的状态。

### 效果组合与边界

- 质变不排除已持有条目，抽中「质变：彩」时继续连锁，每次额外取得均保留自身并产生独立持有实例，正常处理取得收益。首版只有银→金→彩，最多连续升档两次；额外取得按发生时的回合确定取得阶段。
- 「我为歌狂」必须选择当前可取得数量，即请求数量与可用 LIVE 数量的较小值；零候选仍可确认继续。检索不能暴露主卡组顺序，完成后洗切主卡组。
- 「恶魔形态」「来财」取得当回合只提供即时收益，后续增长／抽牌从下一回合开始。「偏差认知」按每份实例的取得回合独立递减。
- 「小画家」的三色门槛看印刷必要心；逐色加 1 看普通修正后的必要心，因此其他效果新增加的必要颜色也适用。未满足三色门槛时仍逐色加 1，但保留灰心必要数量。
- 海克斯判定替换先执行；仍为空判的成员再接受普通判定授予，随后处理颜色替换。「拒绝赌博」的灰判可以满足「压根没漏儿」的有效判定条件；多份相同替换不会变为多个灰判或加 4 分。
- 「压根没漏儿」计入追加声援；整批重新声援后使用新批次。声援牌之后被回收或移动仍属于已公开事实，其他解决区卡牌和未公开牌不计入。分数加成只在 LIVE 成功时计入。
- 首版主动能力和取得检索不提供撤销。每份「会玩」「好好睡好好睡」分别计算每回合次数，不共享同名能力的使用额度。

## 玩家体验与信息权限

### 大厅与海克斯池

娱乐模式统一展示自由构筑、开盒战、海克斯的公开房间。点击玩法标签时，将对应房间移到前面并通过视觉强调区分，其他房间仍可加入或观战；「全部」恢复默认顺序。标签可预选建房和找人的玩法，但加入列表中的房间始终采用该房间的实际规则，自动匹配按玩法隔离。

海克斯复用现有选组、开局确认、猜拳、换组和再战流程，后续操作保留本房间的玩法身份。使用玩家已有卡组，不因浏览海克斯或选择玩法而创建、修改账号卡组。

玩家可以从娱乐大厅及对局内查询完整的可抽取海克斯池，也可以不登录直接访问查询页。目录只展示当前可抽取能力，支持稀有度筛选和名称／效果搜索，包含完整规则；数量、分组与正式抽取目录一致。

查询界面应紧凑，以布局、选中态和数量表达分组，不堆叠重复标题和解释文字。手机单列、桌面双列；搜索按需展开，收起时清除搜索条件并保留稀有度筛选。查询不改变对局状态、使用次数或尚未确认的选择；关闭后返回原入口，保留大厅状态。

### 对局操作、观战与恢复

选择界面展示本轮稀有度、三项完整规则、每格剩余重抽机会与双方确认进度。对局中可查看双方已持有能力，持有者能找到自己的合法起动入口并完成目标选择。选牌时应能查看卡面、所在区域和完整资料；检索面板收起后可重新打开，进度保持。

本地调试与真人对局共用规则命令和牌桌，调试入口可预设已实现能力以便验证。观战与回放只读，按各自授权视角展示；对手的手牌、候选、牌堆顺序与私密检索数据不得先传给前端再隐藏，也不得通过错误提示或日志泄露。

抽取、重抽、锁定、取得和发动的权威结果必须可恢复和追溯。连接中断后读取既有状态，不能重新抽取；恢复不能重放收益或刷新使用次数。普通无海克斯对局保持原行为。历史回放支持相应状态的授权展示，不据此承诺整局确定性重演或进行中对局跨进程恢复。

## 后续扩展需求与待裁定边界

本节均为尚未进入首版池的提案约束，不作为开放承诺或排期。每项必须保留工作簿的完整效果；混合能力不能只实现其中容易的一段就加入自动抽取池。稀有度不表示实现难度。

### 常规动作、成长与历史条件

「年轻就是好」「堕天之力」「正面对决」等涉及双方选择的能力，需明确选择者、顺序、可否放弃及公开时机。「长板效应」应在指定能力结算时读取心池并补差一次，不能随之后增心不断重新拉齐；颜色集合是否包含灰／万能心及持续期限仍需裁定。

「猛虎下山」「传说开幕」「废物利用」「机械降神」等必须明确历史范围、卡牌身份、结算时点及取得前历史是否计入。“上次 LIVE”是否跳过未表演回合，需要单独确定。

「没钱是万万不能的说喏！」的手牌归零条件须覆盖同一次效果中先弃光再抽牌的情况，不能只看结算结束后的手牌。「梨子酱先不说……」的预制 LIVE 需明确按实例、同名还是编号追踪；上回合声援清理进入休息室的 LIVE 也不能漏记，本回合才进入休息室不等于“之前回合”。

### 登场、费用与身份

「4进11大王」「抢凳子」「奥义：反复横跳」需明确费用选项与其他减费的叠加、位置调整的限制，以及是否产生移动或登场事实。「融合召唤」「武圣」须区分印刷身份、当前有效身份和本次使用方式，明确材料、产物与跨区后的身份处理。

「乱战」同时包含牌顶公开、特殊登场或提前放置 LIVE，须确定中央已被占用时如何处理，以及提前放置与盖牌上限、补手数量的关系。「那家伙更重要吗😡」须明确换手离场替换与重新登场的次序。

### 资源与通常阶段替换

「七星」「退钱！」「联名充电宝」「白嫖」须明确资源来源、数量、消费窗口及期限。「白嫖」返还实际支付的费用，需要确定哪些“打出”动作适用；「退钱！」按成员费用产生资源时，须裁定使用印刷值还是离场前有效值。

「天人形态」需明确额外能量的来源。「闪光抽卡」「电表倒转」改变通常阶段动作，须保留其他回合流程和能力的合法顺序。「广义跳费」需逐项确定替换对象、是否视为费用支付完成、同一动作能否继续替换，以及原动作中断后的继续方式。

「开摆」必须同时落实不能 LIVE 和不能用效果影响对方的限制；后者需明确是禁止发动、限制目标还是跳过结算中的对手部分。3／2／1 回合如何计期、到期收益及储存资源规则均需确定，并覆盖同时影响双方或无需指定目标的效果。

### 区域移动、更新与牌堆中的正面牌

「战未来」「牌烧完了我打什么」「现世与冥界的逆转」「垃圾分类」「预见」「掏🐶」需区分移动前替换和入区后再移动；规则事件必须描述实际发生的结果。多个目的地替换的选择与优先级、费用移动能否被替换需明确。

「现世与冥界的驻留」在更新中选择保留卡后，必须能继续此前未完成的抽牌或检视。例如抽两张时只剩一张，应在更新选择后继续剩余抽牌；全部保留后仍为空牌堆的处理及次数消耗时机必须明确。

「夹心面包恶作剧」须区分卡牌所有者、当前区域所属玩家与查看权限，覆盖插入对手牌堆前三张以外、声援、检视及回到规定区域的处理。正面标记不能等同于整副牌堆公开；身份和位置何时可见，以及洗切、露顶、跨区后标记是否保留，需要分别裁定。

### 声援过程

「闪光声援」「安可！」「命运」「冲鸭！」改变声援流程，需明确公开批次、追加声援能否递归、更新发生时的继续方式和判抽时点。「命运」还需确定逆位标记的生成、保留及跨区规则，并保证相反判定作用于对手；逆位不等于成员的待机状态。

「冲鸭！」的成功条件不能仅按总心数与棒数求和，须遵守颜色匹配及单张声援可能产生多个心的规则。已实现的有限判定替换不代表这些声援过程变化均已支持。

### 能力授予、改写与响应

「闪亮登场」「激奏」「冰冷的成员温暖的歌」「瓦学妹压力」需明确授予对象、合法发动窗口、来源生命周期及次数归属。

「回归基本功」「听见你说，内战看」「数值怪」「自适应学历」「电量告急」需列明实际支持的能力形状，覆盖登场限制、费用、常时效果与排队中的能力。不能仅删改显示卡文就视为能力被移除或改写。「回归基本功」的棒、灰心变化及手牌与休息室交换也属于完整效果，其作用对象、窗口和次数仍需裁定。

「回响形态」再次发动仍需支付费用；目标是否重选、原能力次数上限及来源离场后的资格待定。「效果遮蔽者」需明确对手响应窗口、原能力恢复或取消，以及响应能否再被响应。现有双方轮流选牌不等于任意时点均可插入响应。

### 舞台、额外区域与堆叠

「大师决斗」「奇美拉」「合而为一的思念」「通灵盘」须重新定义成员数量、中央／左右／正对面、换手和退场等规则，并明确额外区域是否属于舞台。「战车」等按固定位置编号的效果需同步裁定。

「3星5费」「先吃饭吧」「○」等须明确可叠放的卡牌类型、来源、下方卡的能力和宿主离场后的去向。舞台成员转为下方卡时，其原有附属卡、能力和离场事实需要完整处理；下方卡不自动视为同区独立成员。

### 成功区与胜利

「幽魂形态」「黏着高手」「阿宅栗子球」「小丑学院」「守备表示」涉及最终比分或放置资格，不能将禁止放置误解为 LIVE 未成功。「碾压」须同时包含取得时清空成功区并抽牌、后续放置的比分差要求及胜利门槛变化。

「贷款奖杯」须在宣告终局前处理还贷；「意⭐义⭐不⭐明」等特殊胜利须明确检查时点和终局原因。多种胜利条件、私密标记、放置取消、双方同时达成条件的优先级，以及原文固定张数与基础规则的关系，均需裁定后开放。

### 检视、宣言与暂存

「作弊」「蛊惑」「梨子酱先不说……」「为什么要演奏」「破军」须明确查看范围、是否包括牌堆顺序、授权期限、宣言目录和质疑顺序。宣言结果由权威规则判断，未授权视角不能从候选、错误或日志推断真实内容。

「破军」的暂时扣置须明确是否计入手牌、能否参与其他效果及回合末归还方式；「蛊惑」需同时确定宣言后有效卡牌身份和合法用途。

### 额外取得、重抽与持有替换

「潘多拉盒子」「好运？！」「冠军连招」须区分抽到、选中、额外取得和替换的时点。「冠军连招」的前期检索／加棒与后期额外重抽属于同一完整条目，不能遗漏其中一段。

替换或失去能力时，持续效果、既有收益、储存资源、次数及待处理效果分别如何处理，尚需裁定。首版质变已确定保留自身并允许升档连锁，但这不构成其他随机或替换能力的通用规则。

### 外部资料与线下条件

冠军、红白、销量、东蛋、罕度、动物标识和卡图角色等必须有明确资料来源与判定口径，并在对局中保持稳定。「小保底」的理想最终分数需要定义卡效条件、上限及无界增长的处理，不能等同于印刷分数。「你什么销量」公开的应是本局初始构筑清单，不包括当前手牌分布和牌堆顺序，公开时点需确定。

视频、点赞、唱名、语言限制和线下仪式必须先确定线上表达；「赌圣」「许愿」「NEXT CARD」须明确外部卡的来源与合法性，「低语」须明确代打权限，「猜拳小子」须明确局内窗口。不能静默替换成自动奖励。「25252」的 2.5 分须有完整的数值与展示规则。

「冰淇淋之心」引用的能力、「死者苏生」的苏生限制、「绝妙舞步」的“1 的 x 次方”及「机械降神」可省略的线下条件等不完整文案，必须裁定后再进入开发范围。

## 验收要求

首版及后续每次扩池均按实际纳入的能力验收，无需预先证明全部 125 项组合。需求完成至少包括：

- 完整对局：第 1／3／5 回合选择与通常流程衔接正确，双方任意确认顺序结果一致，未完成选择或检索时不提前恢复／抽牌／处理回合开始效果；能继续到正常终局。
- 权威操作：拒绝越权、旧轮次、旧候选、额外重抽、重复发动及非法目标；重复请求不重复收益，拒绝操作不产生部分支付或移动。
- 效果正确：覆盖完整取得与后续能力、同名实例、阶段增长、次数、无牌可抽、检索不足、更新、条件失效和实际 LIVE 成败；预览、实际结算与展示一致。
- 信息隔离：分别验证本人、对手、观战和授权回放；候选、锁定项、私密检索和隐藏卡顺序不泄露。公开持有与取得收益的时点正确。
- 中断与恢复：重连和状态恢复延续候选、重抽次数、锁定、检索与使用次数，不重新随机、重发收益或重复推进回合；普通对局恢复保持原行为。
- 大厅与桌面：玩法标签只调整展示优先级，其他房间仍可操作，加入遵守目标房间规则；匹配隔离、换组、再战和池查询符合预期，手机／桌面及明暗主题可用。
- 回归范围：覆盖受影响的普通卡效、基础规则和共享操作；复杂条目须验证其实际交互，如移动替换与入区触发、能力替换与持续收益、成功区取消与胜利检查。

规则、服务及隔离浏览器验证不等于生产账号全链路验收。正式开放还需完成目标环境准备、真实账号建房／选组／双端对局／重连／观战及历史页面验证，并通过试打评估稀有度概率、同名叠加与效果平衡。
