# 玩家大厅方案比较

登录后大厅的静态交互原型。当前已选定 C · 对战中心，默认打开 C；A、B 保留用于对照。C 已据此落地到正式 `HomePage`；本目录仍保留独立示例，未连接实际账号、卡组、房间或匹配服务。实际权限、入口开关及数据行为以正式页面和[产品视觉系统](../../product-visual-system.md#83-玩家大厅)为准。

直接打开 [index.html](index.html)，也可使用现有本地开发服务访问本目录。HTML、CSS、普通 JavaScript 和图片均采用相对路径，支持 `file://` 预览。

## 三个方向

| 方案 | 组织方式 | 想验证的取舍 |
| --- | --- | --- |
| A · 快捷开局 | 将玩法、当前一副卡组、查看与更换操作、进入对战的动作组织成一个完整任务，旁边保留最近对局 | 卡组上下文充分、操作直接；主要区域仍是一块清楚的准备面板 |
| B · 舞台大厅 | 深色舞台、随当前构筑变化的角色美术、紧凑操作区；教程、观战、历史和卡组入口放在舞台下沿 | 更鲜明的游戏身份与情感表达，同时保持主要操作在手机首屏 |
| C · 对战中心（已选） | 用可选择的玩法目录组织大厅，右侧仅展示当前任务相关的卡组与动作；统一教程入口，常用入口可自定义，间距小幅收紧 | 玩法区别与开放状态更容易扫读，当前卡组占据更少的主页空间 |

原型工具条可切换正常登录、已有房间、无自建卡组、连接中断状态，以及 1、5、20 副示例卡组。无自建卡组时显示 0 副并禁用数量选择；切回其他状态会恢复原数量。主页固定只呈现当前任务所需的一副摘要，卡组总数只影响选择器和管理目的地预览。

## 可操作范围

- 选择玩法：更新当前任务、卡组上下文与主要按钮，页内状态仅保留在内存中。
- 更换卡组：打开带真实卡面的选择器，选中后更新当前构筑；查看构筑可见成员、LIVE、能量与 PT 摘要。
- 管理卡组：打开独立的只读管理目的地预览，与“选择本次使用的卡组”区分。
- 已有房间：主要动作改为“返回房间”，打开房间状态预览。
- 无自建卡组：默认提供平台预组娱乐模式，教程仍直接可达；切换其他玩法会显示构筑入口与限制原因。
- 连接中断：呈现恢复入口，禁止联网玩法的主要动作；教程、构筑查看等预览保留。
- C 的常用入口：默认提供新手教程、观战、历史对局、本地练习；点击“自定义”可增减、排序或恢复默认。保存前的更改可取消，也可以隐藏所有常用入口。教程在 C 的主页只保留这一处入口。
- C 的首页文案：页头使用“Loveca 大厅”；玩法说明集中在左侧入口，右侧仅展示卡组、必要状态与进入所选玩法的动作，不重复玩法标题与介绍。
- 常用入口设置：仅保存到当前浏览器的 `localStorage`，不写入账号。浏览器不允许存储时仍能在当前预览使用，并提示未持久保存。恢复默认需点击“保存”才生效。玩法、卡组和房间等示例状态仍仅保留在内存。
- 其他入口：教程、观战、历史、回放、账户、公告等提供相应目的地预览；A、B 的低频练习与调试入口收入“更多”。

原型到达实际创建房间、匹配、编辑保存等步骤前停止，并明确显示预览终点。

## 查询参数

| 参数 | 值 | 默认 |
| --- | --- | --- |
| `variant` | `a`、`b`、`c` | `c` |
| `scenario` | `normal`、`room`、`empty`、`offline` | `normal` |
| `count` | `1`、`5`、`20` | `5` |

示例：`index.html?variant=c&scenario=room&count=20`。

## 素材与样式

品牌色、系统 UI/CJK 字体栈与规则数据等宽字体遵循 [产品视觉系统](../../product-visual-system.md)。原型未启用字形覆盖不完整的预留字体。

- `assets/*-card.webp`：通过现有本地开发代理只读取回的既有卡面，分别来自 `PL!SP-sd1-001-SD`、`PL!HS-sd1-001-SD`、`PL!N-sd1-001-SD`、`PL!-sd1-001-SD` 的 medium 图片。
- `assets/kanon.webp`、`keke.webp`、`rina.webp`、`rurino.webp`、`hanayo.webp`：来自仓库 `client/src/components/game/card-entrance/` 的同名 PNG，缩小并转为 WebP。
- `assets/avatar.webp`：来自仓库 `assets/icon.jpg`，缩小并转为 WebP。

名称、PT、对手、最近对局、开放状态与房间等均为工具条标识的示例数据；没有增加商业任务、奖励系统或虚构的实时玩家人数。
