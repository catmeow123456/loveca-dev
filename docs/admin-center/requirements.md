# 运营管理中心与运行时配置需求

> 文档类型：需求文档
> 适用范围：运营管理中心、上游新卡同步、快捷表情目录、卡牌效果 AI 提取配置
> 当前状态：现行需求；首批能力已实现

## 1. 目标与边界

- 管理员从统一入口进入内容与平台、卡牌与规则、对局与赛季运营能力；既有模块复用原页面和服务端接口，不复制业务逻辑。
- 需要不发版、不重启即可调整的业务配置使用专用 PostgreSQL 结构和管理页面，不建立可任意增加键值的通用配置编辑器。
- 快捷表情目录是公开运行时配置；AI Base URL、Model ID、启用状态和加密 API Key 是私密运行时配置。
- 上游新卡同步只能预览差异并向 PostgreSQL 新增 `DRAFT` 卡牌；不更新、删除或发布已有卡牌，不向 CloudBase 写入。
- 数据库、JWT、MinIO、SMTP、配置加密主密钥、出站允许列表和资源硬上限仍属于部署配置，管理中心不能修改或放宽。

## 2. 信息架构

管理中心按以下领域组织为单层分组目录；桌面和移动端保持相同的信息顺序，不为少量分类增加第二套页内导航：

1. 内容与平台：快捷表情、平台状态与公告。
2. 卡牌与规则：卡牌数据、上游新卡同步、卡牌效果 AI 提取、PT 限制表与卡组规则。
3. 对局与赛季：联机房间监控、赛季排位管理、卡组分类。

首页只保留一个“运营管理中心”管理员入口。各管理模块的返回操作回到管理中心；直接页面参数仍可用于深链访问。

## 3. 权限与秘密

- 管理中心读取、保存、候选测试和 AI 提取均由服务端同时校验登录与管理员角色；前端隐藏入口不是安全边界。
- AI 配置读取只返回 API Key 是否已配置，不返回密文或明文。管理操作必须显式选择保留、替换或清除 Key。
- API Key 使用部署环境提供的 32 字节主密钥进行 AES-256-GCM 认证加密；密文与主密钥不得存放在同一配置来源。
- 保存审计只记录非秘密字段、版本和 Key 操作类型。Authorization、完整 Key 和上游错误正文不得进入 API 响应或业务日志。
- CloudBase 环境 ID、Secret ID 和 Secret Key 只由后端进程从仓库外的正式环境变量读取；前端、数据库、任务记录和 API 响应都不保存凭据，且不接受旧变量名 fallback。

## 4. 上游新卡同步

管理员先执行“检查新卡”生成 15 分钟有效的持久化预览，确认候选、阻断和 warning 后再创建正式同步任务。执行时必须重读上游并校验来源哈希与候选卡号；任一发生变化都要求重新预览。同一时刻只允许一个正式任务，worker 使用带代际与 token 的租约 fencing；失去租约的旧 worker 不得继续写卡或覆盖任务结果。

图片下载只接受 HTTPS，DNS A/AAAA 任一结果为回环、链路本地、内网或保留地址时整体拒绝，下载连接必须绑定已校验 IP 且不跟随重定向。每个 WebP 对象写入 SHA-256 元数据，只有对象键和内容哈希同时匹配时才能复用；回滚清理失败必须结构化记录。

## 5. AI 配置与提取

管理员可配置启用状态、OpenAI-compatible Base URL、Model ID 和 API Key。候选配置可在保存前以最小图片输入测试多模态调用；测试不得修改当前有效配置。保存使用 revision 乐观锁和单事务审计，冲突或失败时保留上一版本。

提取流程必须满足：

- 浏览器只提交正在编辑的 `cardCode`；服务端从权威卡牌记录和 MinIO `large/<cardCode>.webp` 读取卡图，不接受客户端 URL。
- 每次请求从 PostgreSQL 读取完整当前配置；配置变更从下一次请求生效，不依赖进程内失效。
- 提示词和翻译格式属于代码评审的产品契约，不在管理页面编辑。
- 返回文本只回填当前编辑表单，不自动保存、发布或成为规则引擎卡效；失败不能清空已有输入。

## 6. 出站安全与资源限制

- 默认只允许 HTTPS，主机必须位于部署允许列表；URL 不得包含凭据、查询或 fragment。
- DNS 解析结果默认拒绝回环、链路本地、内网和保留地址。确需内网或 HTTP 上游时，主机必须同时进入对应部署例外列表。
- 禁止跟随上游重定向；调用具有 15 秒默认超时、2 个默认并发、管理员级分钟限频、4 MiB 默认卡图上限和 256 KiB 默认响应上限。
- 部署环境可在代码允许的上限内收紧限制；管理中心不能改变这些值。

## 7. 生效、失败与迁移

- AI 配置表初始为禁用且没有上游信息或 Key。旧 DashScope 环境变量、示例值和空值不会自动迁移。
- 部署主密钥或允许列表缺失时，页面应显示未就绪，服务端拒绝启用或调用。
- 切换必须在停机窗口执行数据库迁移、部署前后端并移除旧浏览器代理；业务路径不保留旧配置 dual-read。
- 本需求不授权修改生产配置、迁移生产秘密或调用真实第三方模型。

快捷表情目录的字段、资源、版本、缓存、消息快照和迁移要求由 [快捷表情需求与设计](../online-mode/match-emote-requirements-design.md) 维护。

## 8. 验收

- 普通用户和未登录访问无法读取、修改或测试私密配置，也不能触发提取。
- 任意管理读取、保存结果和公开配置均不包含完整 API Key。
- 非法/未允许/私网 Base URL、重定向、超时、超大响应、并发和频率滥用被服务端拒绝。
- 候选测试不保存；版本冲突不覆盖；保存后下一次提取使用新配置。
- 卡牌提取只使用服务端可信图片，结果只进入待确认编辑状态。
- 上游同步只向 CloudBase 发出查询与临时图片 URL 请求；非规范卡号、负数规则字段、不安全 DNS 和图片哈希冲突均会阻断对应卡牌。
- 任务超时回收后，原 worker 的续租、逐卡结果和最终状态写入均失败，新任务不会与旧任务并发写卡。
