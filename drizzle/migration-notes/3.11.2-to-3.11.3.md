# 3.11.2 → 3.11.3 部署说明

> 文档类型：专题说明
> 适用范围：从已完成 3.11.2 迁移的环境升级至 3.11.3
> 当前状态：发布材料；不表示生产迁移或部署已经执行

## 数据库迁移

相对 `v3.11.2`，本版新增 `0044_add_casual_rule_modes.sql`。按[生产部署 Runbook](../../docs/production-release-runbook.md)在停机窗口备份后执行 `pnpm db:migrate`。该迁移为休闲桌增加环境约束，并为对局记录增加普通／娱乐模式字段；既有真人在线记录按原规则回填为普通，主题牌桌记录保留空值。具体排空、副本预演、校验和回退边界见[普通与娱乐构筑规则迁移](casual-rule-modes.md)。

新建、找人与定向加入的前后端协议增加必填 `ruleMode`，须协调部署同一发布提交的 API 与前端。迁移和新服务开放前先限制新准入、排空运行中房间并停止旧写入；不得在旧服务仍写入的运行库上单独开放娱乐准入。旧页面发出的缺字段请求会提示刷新。

未完成 `0043` 及此前迁移的环境，应先核对[上一版部署说明](3.11.1-to-3.11.2.md)及实际数据库状态，不能仅凭应用版本推断迁移进度。卡牌数据同步仍按独立流程处理，本次发布不执行同步。

## 环境、资源与验收

本版没有新增环境变量、Docker 配置、对象存储 bucket 或前缀约定。新增的专属登场与 LIVE 演出资源随前端静态文件发布，不需另行上传对象存储。

部署后除 Runbook 常规检查外，核对既有在线记录回填、主题牌桌记录空值、普通／娱乐模式建桌与卡组约束隔离、旧页面刷新提示，以及新旧对战入口、回放和表格对局。迁移前的备份是 schema 回退前提；新增娱乐房间或历史产生后，回退前应先排空房间并备份新历史，不能直接删除模式列。
