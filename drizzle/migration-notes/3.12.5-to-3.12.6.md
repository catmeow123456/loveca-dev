# 3.12.5 → 3.12.6 部署说明

> 适用范围：从已完成 3.12.5 迁移的环境升级至 3.12.6；发布材料不表示生产部署已执行。

## 数据库与部署

按[生产部署 Runbook](../../docs/production-release-runbook.md)限制新对局、排空并停止旧写入，备份后运行 `pnpm db:migrate`。本版按顺序新增两条迁移：

1. `0049_switch_sealed_to_bp8.sql`：开盒战卡池切换为八弹。部署前必须先按原流程结束并关闭所有七弹房间、释放其 `gameplay_participations`；迁移内置检查，遇到未关闭房间或残留占用会报错停止，不自动关房或删改历史牌池。旧环境仅允许保留 CLOSED 行，禁止重新打开。完整步骤、八弹必要印刷与回滚边界见[开盒战切换八弹](switch-sealed-to-bp8.md)。
2. `0050_add_dark_hextech_pool.sql`：扩展 `casual_tables` 环境检查约束，允许黑暗海克斯环境 `CASUAL_DARK_HEXTECH_V1`，必须在 0049 之后执行。不重置已有房间，不修改账号卡组。

八弹开盒依赖上线后发布的 P+、PE 等必要印刷；未发布齐全时开盒明确报错缺失罕度，服务端不自动发布或跨商品补卡，由用户按正常流程发布。迁移后同步部署同一发布提交的 API 与前端，旧页面应刷新。部署后验收应覆盖：八弹开盒创建／匹配／组牌／再战，黑暗海克斯双池匹配隔离、第 1／3／5 回合选择、重抽与候选隐私。黑暗池生产开放与真实账号验收仍需另行安排，详见[黑暗海克斯说明](../../docs/dark-hextech.md)。

本版无新增环境变量、对象存储或卡牌同步步骤；没有一次性数据脚本。
