# 3.10.2 -> 3.10.3 生产迁移说明

> 文档类型：人工迁移说明（不是 Drizzle 可执行迁移）
> 适用范围：从 3.10.2 升级到 3.10.3
> 当前状态：发布准备中；尚未在生产执行
>
> 本文只记录 3.10.3 特有的配置与部署变化。通用停机部署流程见
> [`docs/production-release-runbook.md`](../../docs/production-release-runbook.md)。

## 变更范围

本版本不新增 Drizzle migration，不需要卡牌数据、卡图或其他业务数据重同步，也不新增对象存储 bucket、对象格式或持久字段。

壁纸发布链路有以下配置变化：

- 浏览器为 `POST /api/player-wallpapers` 使用独立 90 秒请求预算；其他 API 继续使用通用超时。
- Sharp 图片单步处理默认超时从 15 秒延长到 30 秒；`PLAYER_WALLPAPER_PROCESSING_TIMEOUT_SECONDS` 的允许上限同步放宽到 120 秒。
- `docker-compose.yml` 的壁纸处理超时默认值同步为 30 秒。
- `loveca.conf` 为 `POST /api/player-wallpapers` 对应的精确路径增加 90 秒反向代理收发预算；生产机实际 Nginx 配置必须人工同步并通过语法检查后重载。
- 前端会在选图和保存前按实际裁切区域校验最低分辨率，并把分辨率不足、处理超时和网关失败转换为简短的玩家提示。

候场页新增“可在个人中心声音设置中开启或关闭背景音乐”的提示，不改变既有音效偏好字段或候场状态机。

若生产当前仍为 3.10.1，必须在同一维护窗口先按
[`3.10.1-to-3.10.2.md`](3.10.1-to-3.10.2.md) 执行 `0037_add_matchmaking_audio_preferences.sql`，再继续本文步骤。不得因为直接发布 3.10.3 而跳过 0037。

## 发布前门禁

- API、前端、迁移源码和 Nginx 配置来自同一 v3.10.3 release SHA。
- 候选 `ghcr.io/catmeow123456/loveca-api:v3.10.3` 镜像已按通用 runbook 第 2 节通过固定 `linux/amd64` 平台、runtime 入口语法与 production-only 运行时 import 检查。
- 平台已经进入 `MAINTENANCE`，旧 API、前端和所有数据库写入任务已停止。
- 记录生产 `.env` 是否显式设置 `PLAYER_WALLPAPER_PROCESSING_TIMEOUT_SECONDS`，但不要输出其他环境变量或密钥。
- 保存当前 Nginx 配置副本，并记录旧 API 容器、前端构建和实际 RepoDigest 作为回滚基线。
- 从 3.10.2 升级不改变数据库 schema；若从 3.10.1 直升，仍须按上一份迁移说明完成数据库备份和 0037 迁移门禁。

## 执行

### 1. 同步壁纸处理配置

- 若生产 `.env` 未显式设置 `PLAYER_WALLPAPER_PROCESSING_TIMEOUT_SECONDS`，新 compose 默认值会使用 30 秒。
- 若生产 `.env` 仍显式设置为 15 秒，将其调整为 30 秒；如需其他值，必须保持在 1 至 120 秒范围内，并记录压测依据。
- 把仓库 `loveca.conf` 中 `location = /api/player-wallpapers` 的 90 秒代理配置同步到生产站点配置。

在重载前执行：

```bash
nginx -t
```

语法检查通过后再按生产运维方式重载 Nginx。检查失败时恢复配置副本，不得带错误配置继续部署。

### 2. 部署同版 API 与前端

按通用 runbook 使用同一 release SHA 的不可变 API 镜像，并在停机后从同一 checkout 构建前端。生产环境不得使用 `pnpm db:push`，也不得在运行中的 preview 目录原地构建。

## 迁移后验证

- `/api/health`、`/api/ready` 通过；`version.json` 的版本与 commit SHA 为 v3.10.3 release SHA。
- API 实际容器使用已验证的 `linux/amd64` 不可变镜像。
- 个人中心可正常读取和保存壁纸；低于裁切最低分辨率的图片会直接显示简短提示，不出现原始 5xx 或 504 技术响应。
- 使用有当日发布额度的测试账号上传一张合法 JPG、PNG 或静态 WebP，确认处理时间超过旧 15 秒预算时请求仍可完成；不要使用生产账号的唯一每日额度做重复压测。
- 公共牌桌、赛季排位和娱乐模式候场均显示背景音乐开关位置提示，原有背景音乐和匹配成功提示音设置继续生效。
- 手机端卡牌详情关闭后滚动位置稳定，教程双目标引导无遮挡。
- 平台状态和站点快照读取正常后再恢复 `NORMAL`。

## 回滚边界

- 从 3.10.2 升级且应用或 Nginx 配置失败：恢复旧 Nginx 配置、v3.10.2 API 镜像和旧前端，再执行健康检查与最小业务 smoke；本版本没有新增 schema，数据库无需反向迁移。
- 若从 3.10.1 直升且已执行 0037，数据库回滚继续遵守 `3.10.1-to-3.10.2.md`：有迁移前备份时才能完整恢复 3.10.1；没有备份时保持维护并向前修复。
- 已发布的 `v3.10.3` tag 与镜像 tag 不得覆盖；修复应发布新的 patch 版本。
