# 3.12.4 → 3.12.5 部署说明

> 适用范围：从已完成 3.12.4 迁移的环境升级至 3.12.5；发布材料不表示生产部署已执行。

## 数据库与部署

按[生产部署 Runbook](../../docs/production-release-runbook.md)限制新对局、排空并停止旧写入，备份后运行 `pnpm db:migrate`。新增迁移 `0048_add_hextech_casual_format.sql` 扩展 `casual_tables` 的环境检查约束，允许 `CASUAL_HEXTECH_V1`，不重置已有房间或修改账号卡组。先核对 `0047` 及以前的迁移记录；曾执行开发分支旧编号海克斯迁移的环境需同时核对实际结构，不能假定迁移链完整。

迁移后同步部署同一发布提交的 API 和前端，旧页面应刷新。海克斯房间创建、匹配、选择与双方及观战信息隔离应纳入部署后验收。创建海克斯房间后，旧版本的数据库约束及应用未必能处理新环境，回滚前须按 Runbook 评估数据库备份与数据恢复，不能直接恢复旧约束。

本版无新增环境变量、对象存储或卡牌同步步骤；没有额外的一次性数据迁移。海克斯候选池当前为 24 项，生产开放与真实账号验收仍需另行安排。详见[海克斯说明](../../docs/hextech-online.md)。
