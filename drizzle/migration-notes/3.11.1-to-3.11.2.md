# 3.11.1 → 3.11.2 部署说明

> 文档类型：专题说明
> 适用范围：从已完成 3.11.1 迁移的环境升级至 3.11.2
> 当前状态：发布材料；不表示生产部署、排空切换或烟测已经完成

## 数据库迁移

相对 `v3.11.1`，本版新增两条 SQL 迁移，须在停机窗口按[生产部署 Runbook](../../docs/production-release-runbook.md)执行 `pnpm db:migrate`，并保留数据库备份：

- `0042_add_casual_tables.sql`：新增 `casual_tables`、`casual_table_seats`，并为 `gameplay_participations` 增加 `CASUAL_TABLE` kind 与可空 `casual_table_id`。旧 CASUAL 票据、预留、普通房间与历史对局不做自动转换；旧休闲供给的排空、退役脚本预演与应用、新旧入口切换和回退边界见[社区对战大厅迁移说明](community-lobby.md)。该切换含人工核对步骤，不能只执行迁移后直接恢复准入。
- `0043_add_platform_timeout_settings.sql`：`site_status_config` 新增双方断线判定窗口、全员离线销房期限、休闲心跳宽限与休闲配对确认期限四列，均带默认值和 CHECK 范围约束，无数据补写步骤。断线判定窗口随开局冻结进对局快照；销房与休闲两项为实时读取、下一清理周期生效。六项超时设置可在运营管理中心的时限面板调整，`/api/config` 仅公开裁定三项。

未执行过 `0041` 及此前迁移的环境，须先核对[3.10.6 → 3.10.7 说明](3.10.6-to-3.10.7.md)，不能仅凭应用版本推断数据库状态。

## 环境与对象存储

本版没有新增环境变量、Docker 配置或对象存储 bucket／前缀约定；API 镜像运行时依赖与生产流程不变。人物登场素材、眼部图集与姓名字体随前端静态资源发布，进入对局后按双方卡组静默预取并使用独立于应用版本的持久缓存，不需要上传 MinIO 或卡牌管理。

## 前后端协调更新

按 Runbook 停止新对局、等待正在进行的对局结束，再成套更新同一发布提交的 API 和前端：

- 社区对战大厅改写休闲匹配、公开建桌、房间码加入与观战入口，旧休闲读写接口返回 410；前端和 API 必须同批切换，不能只更新一侧。
- 声援翻牌、LIVE 数值反馈、成员心刀强化与远程快照公开事件水位依赖共享层新事件字段；旧前端配新 API 会漏播反馈，旧 API 配新前端无法进入新大厅。
- 本版新增十一个基础编号卡效与对应卡组登记；卡牌库数据同步仍按既有卡牌管理流程单独执行，不由本部署说明替代。

## 验收与回退

部署后除 Runbook 常规检查外，验收：休闲大厅新建→加入→确认→权威终局→离房全流程、旧休闲接口 410、token 观战仍可用、六项超时设置面板读写、声援翻牌与数值反馈在联机双视角播放、新登场动效首次播放与次局缓存命中。真实双端网络与低端设备性能不由发布 CI 证明。

回退边界以[社区对战大厅迁移说明](community-lobby.md)为准：新服务未承载玩家且旧数据未清理时可整体退回旧入口；旧数据已执行退役脚本或新服务已承载玩家后，不得仅退代码。数据库迁移后的 schema 回退依赖停机备份。
